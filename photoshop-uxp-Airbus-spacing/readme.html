Page Guides Inspector (PS)

UXP Plugin · Photoshop · v1.0.0

InDesign UXP panel "Page Guides Inspector" được port sang Photoshop. Cho phép resize Artboard/Canvas và tự động bố trí 7 brand component (Logo · URL · QR · Main-headline · Campaign-line · Sub-headline · Button-CTA) theo Airbus spacing dùng letter-A làm đơn vị đo. Logo do designer resize thủ công; mỗi lần Apply spacing, plugin auto-size letter-A theo chiều cao logo (chỉ tỉ lệ glyph của letter-A là quan trọng — kích thước tuyệt đối không dùng tới). Component resolve theo tên; letter-A nằm trong group guide.

📄 Xem so sánh chi tiết PSD ↔ InDesign trong info.html.

Features

Artboard / Canvas resize

Resize artboard (editArtboardEvent) + tự trim canvas khít; fallback canvasSize cho doc không artboard. Resolution (PPI) không sửa trong panel.

Airbus spacing

Tự động resize & position 7 component: Logo, URL, QR, Main-headline, Campaign-line, Sub-headline, Button-CTA trên Photoshop layers.

Auto-sized letter-A

Mỗi lần Apply: aH = chiều cao logo hiện tại, aW = letterRef.W × (logoH / letterRef.H) — A tự bám theo logo, giữ tỉ lệ glyph. Không cần baseline / marquee ở luồng thường.

A-guide (no delete)

Resize tất cả marker chữ A trong group "guide", đặt thẻ A quanh mỗi component bằng cách reuse → clone (50% opacity). Không xóa chữ A nào.

Reference-based positioning

Component anchor theo Trim (viền = layer Outline) hoặc component khác (Logo, URL, QR, Camp…). Hệ 2-pass tự resolve dependency.

Layer-effect aware

Mọi phép đọc hình học dùng boundsNoEffects — căn theo mép artwork thật, không lệch theo drop-shadow / outer-glow.

Per-document persistence

Mọi setting (names, anchors, A counts, refs, unit, collapse) + baseline lưu vào localStorage theo doc path — giữ giữa các session.

Undo as single step

Apply layout wrap trong core.executeAsModal — Cmd+Z hoàn tác cả lượt apply trong 1 step.

Required-name validation

Logo + letter-A bắt buộc: validate real-time — ngay khi load doc và khi gõ tên. Không tìm thấy layer theo tên → viền đỏ + error text ngay dưới ô input tức thì. Khi Apply: section tự mở + focus vào ô lỗi. 6 component phụ thiếu tên → group bị disable "name not found", skip im lặng.

Input validation — A count & Canvas size

A count: accepts a positive decimal number, max 5. Keyboard filters block non-numeric characters. On blur, invalid values keep their raw input and show an inline red error below the row (Required / Not a number / Must be 0–5). Apply spacing pre-checks all fields and blocks execution if any value is invalid, requiring the user to fix before re-applying. Canvas size: inline red border on blur for non-positive or non-numeric values.

Create guide (fallback)

Chỉ hiện khi CHƯA có folder guide. User dùng Rectangular Marquee vẽ hộp quanh chữ A trong logo → plugin tạo group guide + layer letter-A (copy, không xoá logo) bên trong artboard. Tạo xong → cả 2 nút fallback tự ẩn.

Capture A from selection (fallback)

Cũng chỉ hiện khi chưa có guide. Dùng Rectangular Marquee vẽ hộp quanh chữ A → nhấn nút → resize layer letter-A về đúng kích thước vùng chọn. Luồng thường không cần vì Apply đã auto-size.

Install & Run

Setup steps

1

Mở UXP Developer Tools

Trong Adobe Creative Cloud → Apps → "UXP Developer Tool" (cài nếu chưa có). Yêu cầu Photoshop >= 24.0.

2

Add plugin

UDT → Add Plugin → chọn manifest.json trong folder photoshop-uxp-resize/.

3

Load & Debug

Mở Photoshop (>= 24.0). Trong UDT row của plugin → bấm Load → panel "Page Guides (PS)" xuất hiện trong Plugins menu.

4

Reload sau khi sửa code

Sửa index.html / index.js / styles.css → UDT → Reload. Không cần build.

Cache issue? Nếu lỗi lạ sau reload: rm -rf ~/Library/Caches/Adobe/UXP/ rồi reload lại.

UI Overview

Document Info

Hiển thị tên document và unit selector. Đổi unit → input Width / Height tự convert (px / in / mm / cm / pt). px là default. Resolution (PPI) chỉ dùng nội bộ để convert đơn vị — không hiển thị trên panel.

Page Setup (collapsible)

1 card: Canvas size (Width / Height). (Bleed / Margin / Columns đã được gỡ — Photoshop không có khái niệm native cho chúng.)

  • Apply page setup — resize artboard (neo trái-trên, nội dung không scale) qua editArtboardEvent + tự trim canvas khít; fallback canvasSize nếu doc không có artboard. Áp dụng vào PSD.
  • Revert page setup — trả kích thước trang về trạng thái ngay trước lần Apply gần nhất (snapshot chụp trước khi resize, đo theo artboard).
Lưu ý: Apply page setup chỉ resize khung trang — không tự dời/scale layer (giống InDesign). Việc tái bố trí là của Apply spacing.

Airbus Spacing (collapsible)

8 input name + nút Set: Set = pure rename — gán tên trong ô cho layer đang select (không pin ID, không lưu baseline). Apply resolve component theo tên.

  • Logo + letter-A là bắt buộc: khi Apply không tìm thấy → ô input viền đỏ + dòng error text ngay dưới ô, section tự mở + focus vào ô. Sửa tên hoặc bấm Set lại → error tự mất.
  • 6 component phụ (URL/QR/Main/Camp/Sub/CTA): tên không tồn tại → group bị disable nhãn "name not found" và skip im lặng khi Apply.
  • letter-A auto-size trên Apply theo chiều cao logo — luồng thường không cần marquee / Capture.

7 component groups: Logo / URL / QR / Main-headline / Campaign-line / Sub-headline / Button-CTA. Mỗi group:

  • Checkbox — bật / tắt component đó.
  • Anchor H / V — Left / Right, Top / Bottom.
  • A count H / V — positive decimal number (0 – 5) used as padding in letter-A units. Only numeric characters are accepted. On blur, invalid values keep their raw input and show an inline red error below the row (Required / Not a number / Must be 0–5). Apply spacing pre-validates all A count fields and blocks execution if any value is invalid.
  • Ref H / V — anchor theo Trim hoặc component khác.
2 nút fallback — chỉ hiện khi CHƯA có folder guide: ngay khi group guide tồn tại, cả "Create guide" lẫn "Capture A from selection" đều ẩn (luồng thường không cần đến).

Nút "Create guide" Fallback (chỉ khi chưa có guide)
Rectangular Marquee (M) vẽ hộp quanh chữ A trong logo → nhấn nút → plugin tạo group guide + layer letter-A (copy từ logo, không xoá logo) trong artboard. Sau khi tạo, cả 2 nút fallback ẩn.

Nút "Capture A from selection" Fallback (chỉ khi chưa có guide)
Khi đã có sẵn layer letter-A nhưng cần căn lại: Rectangular Marquee (M) vẽ hộp quanh chữ A → nhấn nút → letter-A resize về đúng kích thước vùng chọn. Luồng thường không cần vì Apply tự auto-size.

Lần đầu với file mới (chưa có guide)

1

Set Logo

Select layer logo → nhập tên trong Logo name → bấm Set.

2

Kiểm tra guide

Nếu thấy nút Create guide màu cam + cảnh báo vàng → chưa có folder guide.

3

Marquee chữ A

Rectangular Marquee (M): vẽ hộp ôm chữ A trong logo.

4

Create guide

Nhấn Create guide → plugin tạo group guide + layer letter-A (cắt từ logo). Xong → 2 nút fallback ẩn.

5

Resize logo (tuỳ chọn)

Resize logo thủ công cho vừa layout.

6

Set các component khác

Set URL, QR, Main, Campaign, Sub, Button-CTA → bấm Apply spacing.

Sau khi resize logo (luồng thường)

1

Resize logo

Resize logo thủ công đến kích thước mong muốn.

2

Apply spacing

Bấm Apply spacing — thế là xong. Plugin tự auto-size letter-A theo chiều cao logo mới (aH = logoH, aW = letterRef.W × logoH/letterRef.H) rồi tính lại toàn bộ spacing. Không cần marquee / Capture.

Capture A from selection giờ chỉ là fallback (xem Edge case 2) — luồng cập nhật bình thường chỉ cần bấm Apply spacing lại.

Xử lý edge case

Edge case 1 — Không có folder `guide`

Triệu chứng

Mở file → status bar vàng "No 'guide' folder found…" + nút Create guide hiện lên bên cạnh Capture.

Tại sao xảy ra

File PSD chưa có group tên đúng guide (case-sensitive), hoặc đây là file mới.

Cách fix — 3 bước

1

Đảm bảo đã Set logo: Logo name input → chọn layer logo → bấm Set.

2

Dùng Rectangular Marquee (M): vẽ hộp ôm chữ A trong logo (không cần chính xác pixel, rộng hơn 1 chút cũng được).

3

Nhấn Create guide → plugin tạo group guide + layer letter-A (cắt từ logo) bên trong artboard.

Sau thành công: guide đã tồn tại → cả 2 nút Create guide & Capture A đều ẩn, status bar xanh xác nhận kích thước. Từ đây chỉ cần Apply spacing.
Lưu ý: Plugin copy layer logo (Layer Via Copy) — logo gốc không bị xoá hay thay đổi.

Edge case 2 — marker chữ A bị méo / lệch tỉ lệ sau Apply

Triệu chứng

Sau Apply spacing, các marker chữ A trông bè ngang hoặc thót so với chữ A thật trong logo (chiều cao đúng nhưng bề ngang sai).

Tại sao xảy ra

Apply auto-size theo công thức aH = chiều cao logo, aW = letterRef.W × (logoH / letterRef.H) — tức chỉ tỉ lệ glyph (W/H) của layer letter-A được dùng, kích thước tuyệt đối không quan trọng. Nếu layer letter-A bị méo tỉ lệ (vd từng bị scale lệch) thì marker sẽ kế thừa tỉ lệ sai đó.

Cách fix

1

Sửa cho tỉ lệ W/H của layer letter-A khớp chữ A thật trong logo — hoặc xoá letter-A + folder guide rồi tạo lại bằng Create guide (cắt thẳng từ logo nên tỉ lệ luôn đúng).

2

(Tuỳ chọn / fallback) Nếu đang ở file chưa có guide và muốn căn nhanh: Rectangular Marquee (M) ôm chữ A → Capture A from selection để resize lại letter-A.

3

Bấm Apply spacing → marker A tính lại theo tỉ lệ đúng.

Ghi chú: Vì chỉ tỉ lệ glyph được dùng, bạn không cần Capture sau mỗi lần resize logo — Apply tự bám chiều cao logo mới. Capture chỉ hữu ích như fallback trước khi có guide.

Key Concepts

Letter-A là đơn vị đo (auto-size theo logo)

Plugin resolve layer chữ A theo TÊN (resolveLetterRef) — không pin ID. Mỗi lần Apply, đơn vị A được tính lại trực tiếp từ logo & letter-A hiện tại, không đọc baseline nào:

aH = chiều cao logo hiện tại               // logo là wordmark → cap-height = chiều cao "A"
aW = letterRef.W × (aH / letterRef.H)      // bám tỉ lệ glyph của layer letter-A

Vì vậy kích thước tuyệt đối của layer letter-A không quan trọng — chỉ cần đúng tỉ lệ W/H. Khác InDesign (logo tự fit column width): bản PS user resize logo thủ công, A tự bám chiều cao logo. aW/aH dùng để tính padding component (mỗi count = 1 A) và đặt thẻ A guide.

Group guide + Create guide / Capture (fallback)

Apply yêu cầu có group guide (chứa các marker letter-A để resize/clone). 2 helper sau chỉ là fallback bootstrap, hiện khi chưa có guide:

  • Create guide — tạo group guide + layer letter-A cắt thẳng từ logo (tỉ lệ luôn đúng).
  • Capture A from selection — resize lại letter-A sẵn có theo vùng marquee.

Cả hai vẫn ghi airbusBaseline vào localStorage cho tương thích, nhưng Apply hiện không đọc giá trị này — sizing hoàn toàn auto theo công thức trên.

2-pass apply

Component reference Trim (container) resolve trước (pass 1). Component reference component khác (vd Camp ref Main, CTA ref Camp, Sub ref QR) resolve sau khi component target đã đặt vị trí xong (pass 2).

A count — decimal number, 0 – 5

Each component's A count H and A count V fields accept a positive decimal number from 0 to 5 (rounded to 1 decimal place). Default: 2 for all components; Sub-H = 1.

Validation behaviour

  • Keyboard filter (keydown) — only digits, ., ,, Backspace, Delete and navigation keys are accepted; letter and symbol keys are silently blocked.
  • On blur — value is parsed. If valid: normalized to 1 decimal place. If invalid: the raw input is kept as-is (no auto-reset), the field flashes red for 1.2 s and an inline red error appears below the row:
    • Empty → "Required"
    • Non-numeric → "Not a number"
    • Out of range (negative or > 5) → "Must be 0–5"
    The error clears automatically when a valid value is entered.
  • Pre-check before Apply spacing — at the start of applyAirbusLayout(), all 14 A count fields are checked on their raw values. If any are invalid: blur is force-triggered (show inline error), the status bar shows a warning, and Apply is blocked until the user fixes and re-applies.

How count maps to spacing

  • Padding (component positioning) = count × aW (H) or count × aH (V) — computed as float; fractional counts are fully supported. The component edge still sits at exactly count × aW/aH from the reference edge.
  • Guide markers — whole count: N full letter-A tiles placed edge-to-edge, no overlap with each other.
  • Guide markers — fractional count (e.g. 2.5 → aSegs length 3): every segment renders as a full-size letter-A (aW × aH, glyph never squeezed or masked), tiled by a full A step so the tiles never overlap one another.
  • Inward shift: the whole tile chain is shifted toward the component by the remainder (tileCount − count) × aW/aH. So the outer tile aligns exactly with the spacing distance (the trim/border edge), and the extra fractional tile pokes inward — it may overlap the component or inner layers, but never pokes past the border. Whole counts → remainder 0 → no shift.
Design rule: a guide tile may overlap other layers (component / inner layers), but the chain never overlaps itself and never spills outside the border edge.

A guide zones (không xóa)

  • Logo / URL / Main / CTA dùng zone builder thường — A xếp theo grid H × V.
  • QR / Camp / Sub dùng "Fixed 2A column": H side = cntH cột, mỗi cột = 2 A xếp dọc. V side = cntV A xếp dọc.
  • STEP3: xóa mask cũ trên mọi marker trước khi đọc bounds/resize — tránh mask cũ làm sai kích thước khi scale về aW×aH.
  • STEP6: mọi ô đều là 1 chữ A đầy (aW×aH), xếp tuần tự sát nhau, không đè lên nhau. Không còn ô lẻ / mask. Reference letter-A gốc dùng cho ô đầu, thiếu thì clone (A-guide-clone).
  • Reuse marker có sẵn → thiếu thì clone thêm → surplus delete (chỉ clone, không bao giờ xóa reference letter-A).

Layer-effect aware (boundsNoEffects)

layer.bounds của Photoshop phình theo Layer Effect (drop-shadow / outer-glow) ở cả 4 cạnh → căn nhầm mép. Helper boundsOf(layer) trả boundsNoEffects (mép artwork thật) cho mọi phép đọc hình học. Layer không effect → bằng bounds (an toàn).

Artboard-aware resize

Document có artboard: canvasSize không đổi artboard. Plugin phát hiện artboard (getArtboards) rồi set artboardRect qua editArtboardEvent (self-verify bằng đọc lại rect), sau đó trim canvas khít artboard (canvas không tự co khi artboard nhỏ lại). Snapshot/Revert đo theo artboard, không theo currentDoc.width (canvas có thể lệch).

Persistence (localStorage)

Tất cả settings + baseline lưu vào window.localStorage key "pageGuides.ps.page.{doc.path}". Persist giữa các plugin reload trong cùng máy. Không lưu trong file PSD — chuyển máy khác cần set lại.

setLayerGeometricBounds

Photoshop UXP không có direct bounds setter như InDesign. Plugin dùng layer.scale() + layer.translate() (đọc mép qua boundsOf) để vừa resize vừa reposition. Text layers (Main/Camp/Sub/CTA) giữ nguyên w/h → scale tự skip (chỉ translate()) để tránh distort.

Photoshop API notes

  • layer.bounds = {left, top, right, bottom} in pixels — không phải points như InDesign.
  • layer.scale(w%, h%, AnchorPosition) và layer.translate(dx, dy) đều async, phải await.
  • layer.move(targetGroup, Constants.ElementPlacement.PLACEATEND) là sync — không cần await.
  • doc.createLayerGroup({name}) — tạo group, cần trong executeAsModal.
  • layer.duplicate() — async, phải await để lấy reference clone.
  • Canvas resize: {_obj: "canvasSize", width: {_unit: "pixelsUnit", …}, horizontal/vertical: …} (anchor là horizontal/vertical, KHÔNG phải canvasSizeAnchor).
  • Artboard resize: {_obj: "editArtboardEvent", artboard: {artboardRect: {_obj:"classFloatRect", top,left,bottom,right}}} — canvasSize/set-to KHÔNG resize được artboard.
  • layer.boundsNoEffects = mép artwork không gồm Layer Effect (dùng cho mọi phép tính vị trí).
  • Layer mask: tạo bằng batchPlay make channel → mask, using revealSelection (sau khi select vùng bằng set channel selection → rectangle). Xóa mask: delete channel → mask. Layer phải là active layer (select theo id) khi thực hiện.

  • Cmd+Z trong Photoshop — undo toàn bộ Apply spacing trong 1 step (History panel PS).
  • Create guide Fallback (chỉ hiện khi CHƯA có folder guide) — tạo group guide + layer letter-A từ vùng selection trên logo. Tạo xong → ẩn.
  • Capture A from selection (chỉ hiện khi CHƯA có folder guide) — resize layer letter-A sẵn có về kích thước vùng selection. Luồng thường không cần (Apply auto-size). Cả 2 nút này ẩn ngay khi guide tồn tại.
  • Reset options — reset anchor / A count / ref của 7 component về default (Sub-H = 1, còn lại = 2). Không động tới name inputs, checkbox, baseline hay page setup.
  • Apply page setup primary — resize artboard + trim canvas.
  • Revert page setup — trả kích thước trang về trạng thái ngay trước lần Apply gần nhất.

Troubleshooting

Triệu chứngNguyên nhân & Fix
"Open a Photoshop document first." Chưa có document mở, hoặc PS chưa ready. Mở PSD rồi bấm ↻ Refresh.
A count field flashes red + error text appears below the row The entered value is invalid (empty, non-numeric, negative, or > 5). The raw input is kept — fix the value manually (0–5), then click Apply spacing.
Status bar warning — Apply spacing did not run One or more A count fields had an invalid raw value when Apply was clicked. Blur was force-triggered to show inline errors on each bad field. Fix the highlighted fields, then click Apply spacing again.
Canvas size field shows a red border The entered value is not a positive number (empty after trim, zero, negative, or non-numeric). Correct the Width or Height value before clicking Apply page setup.
Ô URL/QR/Main/Camp/Sub/CTA viền vàng Tên input không match layer nào trong document (ngay khi gõ hoặc sau Apply). Group bị disable và component bị skip khi Apply. Sửa tên đúng hoặc bấm Set sau khi chọn layer → viền vàng tự mất. Nếu để trống tên → không hiện vàng (skip hoàn toàn là cố ý).
Ô Logo / letter-A viền đỏ + error text dưới ô 2 field này bắt buộc và validate real-time: ngay khi load doc hoặc khi gõ tên, nếu không tìm thấy layer → đỏ tức thì. Khi Apply: section tự mở + focus. Sửa tên hoặc bấm Set lại → error tự mất.
"Logo has zero size." Layer Logo có bounds rỗng. Kiểm tra layer không bị ẩn hoặc bị crop hoàn toàn.
Nút "Create guide" xuất hiện, cảnh báo vàng Chưa có group guide. Rectangular Marquee (M) vẽ hộp quanh chữ A → nhấn Create guide.
"Make a selection around the A…" Nhấn Capture/Create mà chưa có selection. Rectangular Marquee vẽ hộp ôm chữ A trước.
Marker A bị méo / bè ngang sau apply Tỉ lệ glyph (W/H) của layer letter-A sai — Apply auto-size theo chiều cao logo nên chỉ tỉ lệ được dùng. Sửa tỉ lệ layer letter-A, hoặc xoá guide + tạo lại bằng Create guide (cắt thẳng từ logo). Lưu ý: ô lẻ (count số thập phân) cũng là chữ A đầy (không bị bóp/mask) — nó lòi vào phía trong (đè component), không lòi ra ngoài viền.
Apply spacing lỗi "Object is locked" Group "Guide" đang lock. Mở Layers panel PS → unlock layer/group Guide.
Settings mất sau khi chuyển máy Dùng localStorage — không embedded trong PSD. Cần set lại component names trên máy mới.
Apply page setup: số đúng nhưng layout không đổi Document dùng Artboard — canvasSize không resize artboard. Plugin đã chuyển sang editArtboardEvent; nếu vẫn không đổi, xem log [pagesetup] (artboard×N / chưa đổi).
Component lệch sau Apply spacing Layer có Drop-shadow / Outer-glow làm bounds phình. Plugin đã dùng boundsNoEffects; kiểm tra log [fxchk] (ΔL/ΔT).
Sửa code không có hiệu lực Quên reload trong UDT. Hoặc cache stale — clear: rm -rf ~/Library/Caches/Adobe/UXP/.
