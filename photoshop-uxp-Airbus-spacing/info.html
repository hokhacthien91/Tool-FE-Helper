Page Guides Inspector — PSD ↔ InDesign

Comparison · Info

Đối chiếu đầy đủ chức năng giữa bản Photoshop (photoshop-uxp-resize) và bản InDesign gốc (Page Guides Inspector). Phần lõi Airbus spacing gần như giống hệt; khác biệt chính nằm ở Page setup do Photoshop không có các khái niệm native của InDesign (page / bleed / margin / column / multi-page).

B · Chức năng KHÁC nhau — và TẠI SAO

Chức năngInDesignPhotoshop & lý do
Page resize documentPreferences.pageWidth/Height (page native) Resize Artboard (editArtboardEvent) + trim canvas. Vì sao: PS không có "page"; tương đương gần nhất là Artboard/Canvas → khác API/khái niệm.
khác Bleed 4 ô → documentBleed*Offset (native) Đã bỏ. Vì sao: PS không có bleed native (Roadmap).
khác Margin 4 ô → marginPreferences theo page, vẽ guide lề thật Đã gỡ hẳn. Vì sao: PS không vẽ margin guide native; ở PS nó vô tác dụng nên loại bỏ.
khác Columns + Column width columnCount/Gutter → guide cột + hiển thị column width Không có. Vì sao: PS không có cột native; column width là thứ điều khiển size logo bên INDD (xem dòng "size Logo").
Page picker + "All pages" Chọn page, bảng All pages liệt kê margin/col từng trang 1 document; tab "Layers info" hiển thị size / PPI / số layer. Vì sao: PS không có multi-page.
⭐ Size Logo + đơn vị A logoScale = columnWidth / logoW → logo tự fit cột; aW = letterA × logoScale Logo giữ size user tự resize; aW = baseline.aW × (logoW mới / baseline.logoW). Vì sao: PS bỏ column → mất "column width" để fit. Thay bằng cơ chế baseline (lưu lúc Set chữ A) + resize thủ công.
Đơn vị & Resolution point (pt); không có Resolution pixel (px) + ô Resolution (PPI) read-only. Vì sao: PS là raster, tính theo px qua PPI.
Lưu trữ (persistence) Native trong file INDD (insertLabel) localStorage (không nhúng PSD). Vì sao: UXP không ghi ổn định vào PSD (XMP hỏng từ PS 27) → xóa cache UXP là mất.
Xử lý Layer Effect n/a — geometricBounds Mọi phép đọc dùng boundsNoEffects. Vì sao: layer.bounds của PS phình theo glow/shadow → căn nhầm mép.
Undo block doScript(… UndoModes.ENTIRE_SCRIPT) core.executeAsModal(fn, {commandName}). Vì sao: API undo khác giữa 2 host.
Layer search doc.allPageItems (flat) Đệ quy doc.layers. Vì sao: PS không có flat list page items.
