Banner Cloner

Clone a single source artboard into multiple banner sizes, then export the whole set as JPG/PSD/PNG assets — all without leaving Photoshop. Built for production banner-ad workflows where one master design needs to ship across 10+ sizes with variants.

Who is this for? Designers and motion artists in agency/studio teams producing display-ad banner sets (300x250, 728x90, 970x250, …) from a single master design. Pairs well with a JSON layout spec coming out of Figma or a sister tool.

1. Quick Start

  1. Open your master PSD in Photoshop and select any layer inside the source artboard (the plugin walks up to the parent artboard automatically).
  2. Open the panel: Plugins ▸ Banner Cloner.
  3. Type or pick target sizes (e.g. 300x250 728x90 970x250) — separated by spaces or commas. Variant prefixes are supported: v1-300x600, v2-300x600.
  4. Click Clone Artboards. Each new size appears as a fresh artboard in the same document, side-by-side with an 80px gap.
  5. (Optional) Click Export to save all artboards as JPG + PSD into a structured output folder, or Split to Documents to break each artboard into its own PSD file.
  6. (Optional) Switch to the Assets tab to export individual layer/group assets per artboard.

3. Core Features (in detail)

3.1 Clone Artboards

Duplicates the selected source artboard into multiple new artboards in the same document. The original is preserved and never modified. Each clone is positioned to the right of the rightmost existing artboard with an 80px gap.

  • Same-doc cloning — fastest workflow; everything stays in one PSD until you decide to split.
  • Smart positioning — finds the rightmost edge of all existing artboards and lays new ones out from there. Original artboard position is restored if it drifts during cloning.
  • Variant-aware — sizes prefixed v1-, v2-, … are kept distinct; rules apply per variant.
  • Three layout modes, picked automatically per size:
    • JSON rules — when a layer rule exists for the target size (highest priority).
    • Smart match — when no rule but Smart Match is on. Auto scales/repositions/cover-fits content groups.
    • Canvas only — when both off; just resizes the canvas, leaves layers untouched.

Built-in preset sizes (one-click chips):

300x250 300x600 160x600 728x90 320x50 300x50 970x250 480x320 1080x1080 1080x1920 1920x1080 1080x1440 1080x1350

3.2 Smart Match (auto-layout)

Toggle in Settings. When enabled and no JSON rule exists for a size, the plugin:

  • Captures the source artboard's content layout (groups + their bounds) before cloning.
  • For each target size, scales content groups proportionally to fit the new canvas.
  • Repositions groups to maintain visual balance (centered/anchored).
  • Treats the layer/group named in Background Layer (default GG-background) as cover-fill — it's scaled to fully cover the new canvas, never just repositioned.
  • Falls back to fitting individual content layers inside the canvas when no group structure is found.
First-pass layouts only. Always review and polish manually before delivery.

3.3 Layer Rules (per-size)

Define explicit position, size, and style overrides per layer per target size. Rules can be:

  • Auto-synced from your target-sizes list — every size in the input field gets a row in Settings.
  • Imported from JSON — supports two formats:
    • Rules format — moduleName + sizes[] + elements[].
    • Layer-full format (PSD-tree) — exported by Banner Cloner's own Export Layer JSON or by sister tooling. Auto-detected and converted on import.
  • Single-variant collapse — if your import has only v1-300x600 for a given dim, it's automatically renamed to 300x600. Multi-variant dims keep their vN- prefix.
  • Exported as JSON via Export Layer JSON — captures the full layer tree (text, fills, gradients, effects, masks, smart-object refs).
  • Re-applied to existing artboards via Apply Rules to Existing — re-runs rules without re-cloning. Match key is the size suffix in the artboard name (v2-300x600 or 300x600).
  • GG- prefix gate (optional) — when on, rules apply only to layers whose names start with GG- (e.g. GG-headline, GG-cta). Other layers are ignored.

3.4 Background cover scaling

The layer/group named in Background Layer (default GG-background) is treated specially:

  • In Smart Match mode → scaled as cover to fully fill the new canvas.
  • In JSON rules mode → scaled and positioned per its rule entry.
  • The matcher is case-insensitive and reads from a saved localStorage value, so your custom background name persists across sessions.

3.5 Export (all artboards)

Visible only when the active document has more than 1 artboard. Workflow:

  1. Click Export → pick a parent folder.
  2. Plugin creates: {parent}/{base}-output-working-file-{HHMM-DDMMYYYY}/
  3. Inside, two subfolders: output/ for JPGs, working-file/ for editable PSDs.
  4. Each artboard → 1 PSD (full quality, maximize compatibility on) + 1 JPG (quality 8, white matte).
  5. JPG width is capped at 3000px; oversized banners are downscaled while preserving aspect ratio.
  6. All filenames are lowercased and sanitized.

3.6 Split to Documents

Each artboard becomes its own PSD document (one window per banner size). Useful when you need to hand off individual files for review or upload. After splitting, the Documents tab appears and lets you batch-export everything in one click.

3.7 Export Layer JSON

Saves a complete, lossless JSON representation of every selected artboard's layer tree. Captured fields per layer:

  • Geometry — bounds, position relative to artboard, size.
  • Text — font family, weight, size, color, line-height, tracking, alignment, text content.
  • Fills — solid color (RGB), gradient (with stops + angle, CSS-direction-friendly).
  • Effects — drop shadow, inner shadow, outer/inner glow, stroke, gradient overlay.
  • Border radius — corner radii on shape layers.
  • Transform — rotation, flip, scale.
  • Masks — vector masks + raster mask gradient analysis (gradient direction, stop colors/opacities).
  • Smart Objects — original src filename, vector vs raster detection.
  • Asset filename binding — if you ran Export Assets first, the JSON's src field points to the actual exported PNG/JPG instead of the raw PSD reference.

3.8 Export Assets (per-artboard)

Exports individual layer/group assets across selected artboards. The Artboard picker at the top of the Assets tab lets you choose which artboards to scan. After scanning, each detected asset appears as a row with editable size mode, scale, and format.

  • Per-asset controls — cycle through size mode (A/B/C/D), scale (1×/2×/3×), format (PNG/JPG), or rename the export.
  • Search & collapse — filter the asset list by name, or collapse all rows for a denser view.
  • Duplicate detection — two assets with the same final filename are flagged in orange so you can rename one before export.
  • Show in PS — every row has a button that selects that layer in Photoshop.
  • Add Group — manually add an extra group as one flattened asset (useful when scan missed it).
  • Ignore list — comma-separated keywords; layer names containing any keyword are skipped.
  • Hidden layers are skipped automatically.
  • Output structure:
    • Default mode → {picked-folder}/assets-{docname}-{timestamp}/
    • Advanced mode (Custom path) → {path}/{size}/assets/ per artboard. The root path must already exist (no auto-create) and must be absolute.
  • info-image.html (Advanced) — generates a gallery HTML at the export root showing every exported asset grouped by size. Quick visual sanity check.
  • "gg-" filter (Advanced) — only export layers/groups whose names start with gg-. Strips the prefix from the output filename so files come out as logo.png not gg-logo.png.

3.9 Apply Rules to Existing

After importing JSON, click Apply Rules to Existing in Settings to re-run the layout pipeline on every artboard already in the document. Useful when you've tweaked the JSON and want to update without recloning. Only artboards whose name contains a recognized size suffix are touched.

3.10 Refresh Source

Clicking Refresh Source (Artboards tab info card) re-detects the active artboard from the current selection. Use this whenever you change selection in Photoshop mid-session.

3.11 Logs panel

The bottom panel logs every action with timestamps. Behaviour:

  • Errors get a red highlight + 3-second flash on the header to grab attention.
  • "Complete" / "created" lines get a green highlight.
  • Errors auto-expand the panel if it was collapsed.
  • Copy button copies the entire log to clipboard for sharing.
  • Clear resets to Ready.
  • Click the Logs title to collapse/expand.
  • [PERF] entries appear when DEBUG_PERF is on — round-trip timings for tuning.

4. Asset Export Modes (A / B / C / D)

Each asset row in the Assets tab has a size mode toggle. Cycle through them by clicking the mode button.

ModeWhat it doesBest for
A — Layer bounds Exports the layer at its full layer bounds. Output canvas = layer size. Logos, icons, free-floating shapes that should keep their full extent.
B — Clip to artboard Exports only the visible intersection of the layer with the artboard. Output canvas = visible overlap area. Background images that overflow the artboard — you only want what's actually visible. Forced when Custom output path is set.
C — Trim transparent Like A, but trims transparent edges off the result. Sprite-style assets where padding is just empty pixels.
D — Edit Contents Opens a Smart Object's source content and exports that. Skipped for vector SOs. Raster Smart Objects where you want the original embedded resolution rather than the on-canvas size.

Scale options per asset: 1× / 2× / 3× (default 2× outside Advanced mode, 1× inside).

Format options: PNG (default) or JPG (uses the JPG quality from Advanced settings; default 75).

5. JSON Formats

5.1 Rules format (canonical)

Authored manually or generated by sister tooling. Shape:

  • moduleName — campaign / module label, shown in the Settings info card.
  • sizes[] — list of { name, width, height }. Drives the size keys used to look up rules.
  • elements[] — per-layer entries with per-size overrides for position, size, font size, color, etc.

5.2 Layer-full format (PSD tree)

Output of Export Layer JSON — a deep snapshot of an artboard's layers. Auto-detected on import and converted to rules format. Used internally to:

  • Round-trip designs through external tools.
  • Reuse one master's full layer tree as the spec for all sizes.
  • Bind the rule's src to actual exported PNG filenames (after running Export Assets).

7. Tips & Conventions

  • Name your master background group GG-background so it auto-cover-scales without configuration.
  • Prefix layers you want governed by rules with GG- (e.g. GG-headline, GG-cta). Combined with Require GG- prefix, this gives you a clean opt-in convention.
  • Sizes are persisted to localStorage, so the input field repopulates on next launch.
  • Use the Import JSON feature to apply a campaign-wide rule template across all sizes in one shot. The auto-fill will update the Target Sizes input too.
  • If you need 2 layout variants of the same dim (e.g. 300x600 portrait + landscape), use v1-300x600 and v2-300x600. Single-variant dims auto-collapse to 300x600 on import.
  • Refresh Source if you change selection mid-session — it re-detects the active artboard.
  • For Asset export with Custom output path, run Export Assets before Export Layer JSON so the JSON's src fields point at real PNG/JPG filenames instead of .ai/.psd raws.
  • The log panel auto-scrolls; click a log line to copy via the Copy button at the top.

8. Known Limitations

  • Smart-match auto-layout is best-effort; complex designs may still need manual cleanup.
  • Asset export Mode D (Edit Contents) only works for raster Smart Objects — vector SOs are skipped.
  • Custom output path requires the root folder to already exist — no auto-create.
  • JPG export caps width at 3000px (downscaled); PSDs are saved at full resolution.
  • Only Photoshop is supported (UXP). Min host version: 23.0.0.
  • Photoshop's color descriptor stores green channel as grain in some contexts — readers must check both fields to avoid G=0 magenta artifacts.

9. Installation

  1. Install the Adobe UXP Developer Tool (free download from Adobe).
  2. In UXP DT, click Add Plugin and pick this folder's manifest.json.
  3. Click Load. The panel appears under Plugins ▸ Banner Cloner in Photoshop.
  4. The panel docks at the right; minimum size 320×520, preferred 360×760. Resizable up to 1200×2000.
