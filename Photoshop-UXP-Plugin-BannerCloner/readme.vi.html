Banner Cloner

Clone 1 artboard gốc thành nhiều kích thước banner, rồi export cả bộ ra JPG/PSD/PNG asset — tất cả không cần rời Photoshop. Dành cho workflow banner ads cần ship 10+ sizes (kèm variant) từ 1 design master.

Plugin này dành cho ai? Designer / motion artist trong các team agency/studio làm display ad banners (300x250, 728x90, 970x250, …) từ 1 file master. Kết hợp tốt với JSON layout spec xuất từ Figma hoặc tool sister.

1. Bắt đầu nhanh

  1. Mở file PSD master trong Photoshop và chọn 1 layer bất kỳ trong artboard nguồn (plugin tự traverse lên parent artboard).
  2. Mở panel: Plugins ▸ Banner Cloner.
  3. Nhập hoặc chọn target sizes (vd: 300x250 728x90 970x250) — phân cách bằng dấu cách hoặc dấu phẩy. Hỗ trợ variant prefix: v1-300x600, v2-300x600.
  4. Click Clone Artboards. Mỗi size mới xuất hiện thành 1 artboard riêng trong cùng document, xếp kế nhau cách 80px.
  5. (Tùy chọn) Click Export để lưu tất cả artboards ra JPG + PSD vào folder có cấu trúc, hoặc Split to Documents để tách mỗi artboard thành 1 file PSD riêng.
  6. (Tùy chọn) Chuyển sang tab Assets để export từng layer/group asset theo từng artboard.

2. Các tab trong panel

Tab Artboards
View mặc định. Nhập sizes, toggle preset chip, chạy Clone Artboards. Source name + size và JSON status hiển thị bên dưới action bar.
Tab Settings
Bật smart-match, GG- prefix gating, suffix tên, background layer, layer rules theo từng size, import/export JSON, Apply Rules to Existing.
Tab Assets
Scan + export theo nhiều artboard. Mỗi asset có size mode (A/B/C/D), scale, format (PNG/JPG), search, collapse all, custom output path validate chặt.
Tab Documents
Mặc định ẩn — chỉ hiện sau khi Split to Documents mở nhiều PSD. Cho phép batch export tất cả ra JPG + PSD trong 1 click.

3. Chức năng chính (chi tiết)

3.1 Clone Artboards

Duplicate artboard nguồn đang chọn thành nhiều artboard mới trong cùng document. Bản gốc luôn được giữ nguyên, không bao giờ bị sửa. Mỗi clone được đặt phía bên phải của artboard ngoài cùng bên phải, cách 80px.

  • Same-doc cloning — workflow nhanh nhất; mọi thứ ở trong 1 PSD đến khi bạn quyết định split.
  • Định vị thông minh — tìm cạnh phải xa nhất của tất cả artboards hiện có rồi xếp tiếp. Position của artboard gốc được restore nếu bị drift trong lúc clone.
  • Variant-aware — sizes có prefix v1-, v2-, … được giữ riêng biệt; rules apply theo từng variant.
  • 3 layout modes, plugin tự chọn theo từng size:
    • JSON rules — khi có layer rule cho size đó (ưu tiên cao nhất).
    • Smart match — khi không có rule nhưng Smart Match đang on. Tự scale/reposition/cover-fit content groups.
    • Canvas only — khi cả 2 đều off; chỉ resize canvas, layer giữ nguyên.

Preset sizes có sẵn (chip click 1 phát):

300x250 300x600 160x600 728x90 320x50 300x50 970x250 480x320 1080x1080 1080x1920 1920x1080 1080x1440 1080x1350

3.2 Smart Match (auto-layout)

Toggle trong Settings. Khi bật và không có JSON rule cho size, plugin sẽ:

  • Capture content layout của artboard nguồn (groups + bounds) trước khi clone.
  • Với từng target size, scale các content group theo tỉ lệ vừa với canvas mới.
  • Reposition groups để cân bằng visual (centered/anchored).
  • Coi layer/group có tên trùng Background Layer (mặc định GG-background) là cover-fill — scale phủ kín canvas mới, không chỉ reposition.
  • Fallback: fit từng content layer vào canvas khi không tìm thấy cấu trúc group.
Chỉ là layout pass đầu. Luôn review và chỉnh tay trước khi giao file.

3.3 Layer Rules (theo từng size)

Định nghĩa rule cụ thể về vị trí, kích thước, style cho từng layer ở từng target size. Rules có thể:

  • Auto-sync từ danh sách target sizes — mỗi size trong input sẽ có 1 row trong Settings.
  • Import từ JSON — hỗ trợ 2 format:
    • Rules format — moduleName + sizes[] + elements[].
    • Layer-full format (PSD-tree) — output từ chính Export Layer JSON hoặc tool sister. Tự detect và convert khi import.
  • Single-variant collapse — nếu import chỉ có v1-300x600 cho 1 dim, plugin tự rename về 300x600. Multi-variant dims giữ nguyên prefix vN-.
  • Export ra JSON qua Export Layer JSON — capture toàn bộ layer tree (text, fill, gradient, effect, mask, smart-object refs).
  • Apply lại cho artboards đã có qua Apply Rules to Existing — chạy lại rules không cần clone lại. Match key là size suffix trong tên artboard (v2-300x600 hoặc 300x600).
  • GG- prefix gate (tùy chọn) — khi bật, rules chỉ apply cho layer có tên bắt đầu bằng GG- (vd GG-headline, GG-cta). Layer khác bị bỏ qua.

3.4 Scale background dạng cover

Layer/group có tên trong Background Layer (mặc định GG-background) được xử lý đặc biệt:

  • Mode Smart Match → scale dạng cover, phủ kín canvas mới.
  • Mode JSON rules → scale + position theo entry rule của nó.
  • Matcher case-insensitive và đọc từ giá trị localStorage đã lưu, nên tên background custom của bạn được giữ qua nhiều session.

3.5 Export (tất cả artboards)

Chỉ hiện khi document active có nhiều hơn 1 artboard. Workflow:

  1. Click Export → chọn parent folder.
  2. Plugin tạo: {parent}/{base}-output-working-file-{HHMM-DDMMYYYY}/
  3. Bên trong có 2 subfolder: output/ chứa JPGs, working-file/ chứa PSDs editable.
  4. Mỗi artboard → 1 PSD (full chất lượng, maximize compatibility on) + 1 JPG (quality 8, white matte).
  5. Width JPG cap ở 3000px; banner quá lớn sẽ được downscale, giữ tỉ lệ.
  6. Tất cả filenames đều lowercase và sanitize ký tự đặc biệt.

3.6 Split to Documents

Mỗi artboard trở thành 1 PSD document riêng (1 cửa sổ / 1 size). Tiện khi cần handoff từng file để review hoặc upload. Sau khi split, tab Documents hiện ra cho phép batch export tất cả trong 1 click.

3.7 Export Layer JSON

Lưu JSON đầy đủ, lossless về cấu trúc layer tree của các artboard đã chọn. Mỗi layer capture:

  • Hình học — bounds, vị trí relative tới artboard, size.
  • Text — font family, weight, size, color, line-height, tracking, alignment, nội dung text.
  • Fill — solid color (RGB), gradient (kèm stops + angle, theo CSS direction).
  • Effects — drop shadow, inner shadow, outer/inner glow, stroke, gradient overlay.
  • Border radius — bán kính góc của shape layer.
  • Transform — rotation, flip, scale.
  • Masks — vector mask + phân tích gradient của raster mask (direction, stop colors/opacities).
  • Smart Objects — tên file src gốc, detect vector hay raster.
  • Asset filename binding — nếu bạn chạy Export Assets trước, field src trong JSON sẽ trỏ tới đúng file PNG/JPG đã export, không phải file PSD/AI gốc.

3.8 Export Assets (theo artboard)

Export từng layer/group asset trên các artboard đã chọn. Artboard picker ở đầu tab Assets cho phép chọn artboards nào sẽ scan. Sau scan, mỗi asset hiện thành 1 row có thể chỉnh size mode, scale, format.

  • Per-asset controls — cycle qua size mode (A/B/C/D), scale (1×/2×/3×), format (PNG/JPG), hoặc rename file export.
  • Search & collapse — lọc asset list theo tên, hoặc collapse all rows để view gọn.
  • Duplicate detection — 2 asset cùng tên file output sẽ được flag màu cam để bạn rename trước khi export.
  • Show in PS — mỗi row có nút select layer đó trong Photoshop.
  • Add Group — thêm thủ công 1 group thành 1 asset flatten (khi scan miss).
  • Ignore list — keywords cách bằng dấu phẩy; layer có tên chứa keyword nào sẽ bị bỏ qua.
  • Layer ẩn tự động bỏ qua.
  • Cấu trúc output:
    • Default mode → {folder-chọn}/assets-{docname}-{timestamp}/
    • Advanced mode (Custom path) → {path}/{size}/assets/ theo từng artboard. Folder gốc phải tồn tại sẵn (không auto-create) và phải là path tuyệt đối.
  • info-image.html (Advanced) — tạo gallery HTML ở root export, hiển thị mọi asset đã export, gom theo size. Preview nhanh để kiểm tra.
  • "gg-" filter (Advanced) — chỉ export layer/group có tên bắt đầu bằng gg-. Strip prefix khỏi filename → ra logo.png chứ không phải gg-logo.png.

3.9 Apply Rules to Existing

Sau khi import JSON, click Apply Rules to Existing trong Settings để chạy lại layout pipeline trên mọi artboard đã có trong document. Tiện khi bạn đã chỉnh JSON và muốn update mà không clone lại. Chỉ artboard có size suffix nhận diện được mới bị động.

3.10 Refresh Source

Click Refresh Source (info card tab Artboards) để re-detect artboard active từ selection hiện tại. Dùng khi bạn đổi selection trong Photoshop giữa session.

3.11 Logs panel

Panel ở dưới cùng log mọi action. Behavior:

  • Error có highlight đỏ + flash 3 giây trên header để gây chú ý.
  • Dòng "complete" / "created" có highlight xanh.
  • Error tự động expand panel nếu đang collapsed.
  • Nút Copy copy toàn bộ log ra clipboard để share.
  • Clear reset về Ready.
  • Click title Logs để collapse/expand.
  • Dòng [PERF] hiện khi DEBUG_PERF bật — đo round-trip để tune perf.

4. Asset Export Modes (A / B / C / D)

Mỗi asset row trong tab Assets có toggle size mode. Click vào nút mode để cycle qua các options.

ModeTác dụngPhù hợp với
A — Layer bounds Export layer ở bounds đầy đủ. Output canvas = kích thước layer. Logo, icon, shape free-floating cần giữ toàn bộ extent.
B — Clip to artboard Chỉ export phần overlap visible giữa layer và artboard. Output canvas = vùng overlap. Background tràn ra ngoài artboard — bạn chỉ cần phần thấy được. Bị force khi Custom output path được set.
C — Trim transparent Giống A, nhưng trim các edge trong suốt khỏi output. Asset dạng sprite, padding chỉ là pixel rỗng.
D — Edit Contents Mở source content của Smart Object và export cái đó. Skip vector SO. Raster Smart Object cần lấy resolution gốc embed bên trong, không phải kích thước on-canvas.

Scale options theo từng asset: 1× / 2× / 3× (mặc định 2× ngoài Advanced mode, 1× trong Advanced).

Format options: PNG (mặc định) hoặc JPG (dùng JPG quality từ Advanced settings; mặc định 75).

5. Các format JSON

5.1 Rules format (canonical)

Tạo thủ công hoặc generate từ tool sister. Cấu trúc:

  • moduleName — label campaign / module, hiển thị trong info card Settings.
  • sizes[] — list { name, width, height }. Drive các size key dùng để lookup rules.
  • elements[] — entry theo từng layer với override per-size (position, size, font size, color, …).

5.2 Layer-full format (PSD tree)

Output của Export Layer JSON — snapshot sâu của layer tree 1 artboard. Auto-detect khi import và convert qua rules format. Dùng nội bộ để:

  • Round-trip design qua external tools.
  • Tái sử dụng layer tree đầy đủ của master làm spec cho mọi sizes.
  • Bind src của rule với filename PNG thực tế (sau khi chạy Export Assets).

7. Tips & Conventions

  • Đặt tên group background master là GG-background để tự động cover-scale, không cần config.
  • Đặt prefix GG- cho các layer cần áp dụng rules (vd: GG-headline, GG-cta). Kết hợp với Require GG- prefix sẽ cho convention opt-in sạch sẽ.
  • Sizes được persist vào localStorage, nên input field tự fill lại khi launch lần sau.
  • Dùng Import JSON để apply 1 template rule cho toàn campaign trong 1 lần. Auto-fill cũng update Target Sizes input.
  • Cần 2 layout variant cho cùng 1 dim (vd 300x600 dọc + ngang)? Dùng v1-300x600 và v2-300x600. Single-variant dim sẽ tự collapse về 300x600 khi import.
  • Refresh Source nếu bạn đổi selection giữa session — plugin sẽ detect lại artboard active.
  • Asset export với Custom output path: chạy Export Assets trước Export Layer JSON để field src trong JSON trỏ tới file PNG/JPG thực tế thay vì raw .ai/.psd.
  • Log panel auto-scroll; click 1 dòng log để copy qua nút Copy ở trên.

8. Hạn chế hiện tại

  • Smart-match auto-layout là best-effort; design phức tạp vẫn cần chỉnh tay.
  • Asset export Mode D (Edit Contents) chỉ work với raster Smart Object — vector SO bị skip.
  • Custom output path yêu cầu folder gốc phải tồn tại sẵn — không auto-create.
  • JPG export cap width 3000px (downscale); PSD lưu full resolution.
  • Chỉ hỗ trợ Photoshop (UXP). Phiên bản tối thiểu: 23.0.0.
  • Color descriptor của Photoshop lưu kênh green vào grain trong 1 số context — reader phải check cả 2 field để tránh artifact G=0 magenta.

9. Cài đặt

  1. Cài Adobe UXP Developer Tool (download free từ Adobe).
  2. Trong UXP DT, click Add Plugin và chọn file manifest.json trong folder này.
  3. Click Load. Panel sẽ xuất hiện ở Plugins ▸ Banner Cloner trong Photoshop.
  4. Panel dock ở bên phải; min size 320×520, ưu tiên 360×760. Resize được tới 1200×2000.
