Banner Cloner

Clone 1 artboard gốc (hoặc 1 bộ multi-frame step-animation) thành nhiều kích thước banner, rồi export cả bộ ra JPG/PSD/PNG asset và 1 file JSON layer dump có cấu trúc — tất cả không cần rời Photoshop. Dành cho workflow banner ads production cần ship 10+ sizes (và tuỳ chọn 2–10 frame animation) từ 1 design master.

Plugin này dành cho ai? Designer / motion artist trong các team agency/studio làm display ad banners (300x250, 728x90, 970x250, …) từ 1 file master. Kết hợp với generator web-ui (qua schema JSON banner-cloner-v1) để bỏ qua bước code HTML tay.

1. Bắt đầu nhanh

  1. Mở file PSD master trong Photoshop và chọn 1 layer bất kỳ trong artboard nguồn (plugin sẽ tự đi lên artboard cha). Cmd/Ctrl-click trong panel Layers để chọn nhiều artboard nguồn cùng lúc (vd F1 + F2 + F3).
  2. Mở panel: Plugins ▸ Banner Cloner.
  3. Gõ hoặc click chip target sizes (vd 300x250 728x90 970x250) — tách bằng khoảng trắng hoặc dấu phẩy. Hỗ trợ prefix variant: v1-300x600, v2-300x600. Hỗ trợ prefix frame: F1-300x600, F2-300x600.
  4. Click Clone Artboards. Mỗi size mới xuất hiện thành artboard mới trong cùng document, xếp ngang cách nhau 80px. Workflow multi-source xếp dòng frame phía dưới dòng trước.
  5. (Tuỳ chọn) Click Export để lưu mọi artboard ra JPG + PSD vào 1 folder có cấu trúc, hoặc Split to Documents để tách mỗi artboard thành 1 file PSD riêng.
  6. (Tuỳ chọn) Chuyển sang tab Assets để export từng asset layer/group cho từng artboard.
  7. (Tuỳ chọn) Click Export Layer JSON ở Settings để xuất file schema banner-cloner-v1 dùng cho generator web-ui.

3. Chức năng chính (chi tiết)

3.1 Clone Artboards (single & multi-source)

Nhân bản artboard nguồn thành nhiều artboard mới trong cùng document. File gốc được giữ nguyên, không bị sửa. Mỗi clone đặt bên phải artboard ngoài cùng bên phải hiện có, cách 80px.

  • Same-doc cloning — workflow nhanh nhất; mọi thứ ở trong 1 PSD đến khi bạn quyết định split.
  • Smart positioning — tìm cạnh phải ngoài cùng của mọi artboard hiện có, đặt artboard mới từ đó. Vị trí artboard gốc được restore nếu bị lệch trong lúc clone.
  • Multi-source — Cmd/Ctrl-click để chọn nhiều artboard nguồn cùng lúc. Mỗi nguồn clone 1 dòng đầy đủ target; các dòng xếp chồng dọc, layout gốc giữ nguyên.
  • Variant-aware — size prefix v1-, v2-, … được giữ riêng; rule áp theo từng variant.
  • Frame-token match (Settings → Match source frame token) — khi tên nguồn có prefix frame (...-F2), chỉ những target size cùng prefix frame (F2-300x600) mới được clone từ nguồn đó. Nguồn không có frame token sẽ clone tất cả target (legacy). Có thể tắt.
  • 3 layout mode, tự chọn theo từng size:
    • Uniform scale — khi Uniform scale bật. Bỏ qua cả smart match và JSON rule; chỉ scale canvas + content theo tỉ lệ.
    • JSON rules — khi có rule cho size đó (ưu tiên cao nhất).
    • Smart match — không có rule, Smart Match bật. Tự scale/dời/cover-fit content group.
    • Canvas only — cả 3 đều tắt; chỉ resize canvas, layer giữ nguyên.
  • Progress live — progress bar hiện target hiện tại + tổng.

Preset size built-in (chip 1 click, click để add/remove khỏi input):

300x250 300x600 160x600 728x90 320x50 300x50 970x250 480x320 1080x1080 1080x1920 1920x1080 1080x1440 1080x1350

3.2 Uniform scale (giữ tỉ lệ)

Toggle ở Settings. Khi bật, mỗi target size scale content nguồn đều theo (lấy số nhỏ hơn của targetW / srcW và targetH / srcH), rồi căn lại trong canvas mới. Bỏ qua cả smart match và JSON rule. Hữu ích cho deck thuần uniform khi hướng layout không đổi. Lưu trong localStorage.

3.3 Smart Match (auto-layout)

Toggle ở Settings. Khi bật và không có JSON rule cho size đó, plugin sẽ:

  • Capture layout content nguồn (group + bound) trước khi clone.
  • Với mỗi target size, scale content group theo tỉ lệ để vừa canvas mới.
  • Dời group để giữ cân bằng (centered/anchored).
  • Layer/group có tên Background Layer (mặc định GG-background) được xử lý cover-fill — scale phủ kín canvas mới, không phải chỉ dời.
  • Fallback fit từng layer vào canvas khi không có cấu trúc group.
  • Tôn trọng fit-lock cho group có tên chứa fit-lock — group scale như 1 khối thay vì từng child.
Layout pass đầu thôi. Luôn review và polish tay trước khi giao.

3.4 Layer Rules (per-size)

Định nghĩa override rõ ràng vị trí, kích thước, style cho từng layer trong từng target size. Rule có thể:

  • Auto-sync từ list target size — mỗi size trong input field có 1 dòng ở Settings → Layer Rules.
  • Import từ JSON — hỗ trợ 2 format:
    • Rules format — moduleName + sizes[] + elements[].
    • Layer-full format (PSD-tree) — xuất từ chính Export Layer JSON hoặc tool sister. Auto-detect và convert khi import.
  • Single-variant collapse — nếu import chỉ có v1-300x600 cho 1 dim, sẽ tự đổi tên thành 300x600. Dim multi-variant giữ prefix vN- / Fn-. Frame-token prefix giữ nguyên.
  • Export ra JSON qua Export Layer JSON — capture full layer tree với schema mới banner-cloner-v1 (xem §6).
  • Re-apply lên artboard hiện có qua Apply Rules to Existing — re-run rule mà không clone lại. Match key là size suffix trong tên artboard (v2-300x600, F2-300x600, hoặc 300x600 thuần).
  • Per-layer scale override — rule có thể có field scale để nhân size import với 1 hệ số riêng (chạy bởi computeRuleScale).
  • GG- prefix gate (tuỳ chọn) — khi bật, rule chỉ áp cho layer tên bắt đầu GG- (vd GG-headline, GG-cta). Layer khác bị bỏ qua.

3.5 Background cover scaling

Layer/group có tên trong Background Layer (mặc định GG-background) được xử lý đặc biệt:

  • Mode Smart Match → scale cover phủ kín canvas mới.
  • Mode JSON rules → scale + đặt theo rule entry (kèm rule scale factor nếu có).
  • Matcher không phân biệt hoa thường, lưu localStorage nên tên BG custom của bạn không mất giữa các session.

3.6 Export (mọi artboard)

Chỉ hiện khi document hiện tại có nhiều hơn 1 artboard. Workflow:

  1. Click Export → chọn folder cha.
  2. Plugin tạo: {parent}/{base}-output-working-file-{HHMM-DDMMYYYY}/
  3. Trong đó có 2 subfolder: output/ chứa JPG, working-file/ chứa PSD edit được.
  4. Mỗi artboard → 1 PSD (full quality, maximize compatibility on) + 1 JPG (mặc định quality 8 → ~75 thang 0–100, matte trắng).
  5. Width JPG cap 3000px; banner lớn hơn bị scale xuống, giữ tỉ lệ.
  6. Tên file đều lowercase và sanitize.

3.7 Split to Documents

Mỗi artboard thành 1 PSD riêng (1 cửa sổ / size). Hữu ích khi cần bàn giao file lẻ để review hoặc upload. Sau khi split, tab Documents hiện ra, batch-export mọi file bằng 1 click.

3.8 Export Layer JSON (schema banner-cloner-v1)

Lưu JSON đầy đủ, lossless cho layer tree của mọi artboard được chọn. Plugin tự nhận diện export mode (single / multi-frame / layer-full) từ trạng thái document và gắn nhãn đúng — nhưng có thể override qua Override auto-detection trong Settings.

Shape top-level:

{
  "schema": "banner-cloner-v1",
  "mode": "single" | "multi-frame" | "layer-full",
  "framePrefix": "F",            // khi mode = multi-frame, vd "F"/"Step"
  "exportedAt": "ISO timestamp",
  "artboards": [
    {
      "artboard": "campaign-1200x628-F1",
      "frame": "F1",             // có khi mode = multi-frame
      "width": 1200,
      "height": 628,
      "layers": [ ... ]
    }
  ]
}

Field được capture cho từng layer:

  • Geometry — bounds (top/left/width/height) tương đối với artboard, đã trừ offset của parent group.
  • Text — font family, weight, size, color, line-height, tracking, alignment, content.
  • Fills — solid color (RGB), gradient (kèm stops + angle, dạng CSS-friendly).
  • Effects — drop shadow, inner shadow, outer/inner glow, stroke, gradient overlay (frameFX).
  • Border radius — bo góc shape layer.
  • Transform — rotation, flip, scale.
  • Masks — vector mask + phân tích gradient của raster mask (hướng gradient, màu/opacity stop).
  • Smart Objects — tên file src gốc, phân biệt vector / raster, kích thước embedded gốc.
  • clipTo — tên layer sibling mà layer được clip vào (clipping mask base).
  • Asset filename binding — nếu chạy Export Assets trước, field src trong JSON sẽ trỏ đến file PNG/JPG export thật thay vì raw PSD reference.

Auto-rename duplicate layers (Settings, mặc định bật) — trước khi serialize, plugin rename duplicate trong từng artboard để path unique. Cần thiết cho tool downstream key theo tên layer.

3.9 Export Assets (per-artboard)

Export từng asset layer/group qua nhiều artboard được chọn. Workflow:

  1. Mở Artboard picker đầu tab Assets — search, click All/None, hoặc tick từng artboard. Chọn lưu per-document qua localStorage.
  2. Click Get Images để scan các artboard đã chọn. Mỗi asset detect được hiện 1 dòng.
  3. (Tuỳ chọn) Click + Add Group để add tay 1 group thành 1 asset flatten (khi scan miss).
  4. Control mỗi asset (cycle bằng click):
    • Size mode: A / B / C / D — xem §5 dưới.
    • Scale: 1× / 2× / 3× (mặc định 2× ngoài Advanced, 1× trong Advanced).
    • Format: PNG / JPG (PNG mặc định; JPG dùng JPG quality của Advanced, mặc định 75).
    • Rename: edit tên file output inline.
    • Show in PS: nút chọn layer đó trong Photoshop's Layers panel.
    • Single export: export riêng từng dòng, bỏ qua bulk flow.
  5. Search & collapse — filter asset theo tên, hoặc collapse mọi dòng cho gọn.
  6. Duplicate detection — 2 asset trùng final filename sẽ flag cam để bạn rename trước khi export.
  7. Layer ẩn tự bỏ qua.
  8. Ignore list — keyword cách nhau bằng phẩy (Settings); layer/group tên chứa keyword sẽ bị skip lúc scan.
  9. Click Export Assets để ghi mọi thứ.

Cấu trúc output:

  • Mode mặc định → {folder-chọn}/assets-{docname}-{timestamp}/ với 1 subfolder / artboard.
  • Mode Advanced (Custom path) → {path}/{size}/assets/ cho mỗi artboard. Path root phải tồn tại sẵn (không auto-create) và phải là absolute.

Advanced options (tab Assets → tick Advanced options):

  • Custom output path (bắt buộc khi Advanced bật) — phải absolute, phải tồn tại sẵn. Validate khi submit; field flash đỏ nếu sai.
  • JPG quality (bắt buộc, 0–100) — Mặc định 75. Validate khi submit. Map sang scale Photoshop nội bộ 0–12.
  • Filter "gg-" — chỉ export layer/group tên bắt đầu gg- (không phân biệt hoa thường). Strip prefix khỏi tên file output, ra logo.png chứ không phải gg-logo.png.
  • Generate info-image.html — tạo gallery HTML ở root export sau khi export asset xong. Sanity check nhanh, gom theo size.

Toàn bộ Advanced lưu localStorage nên không mất khi reload panel.

3.10 Apply Rules to Existing

Sau khi import JSON, click Apply Rules to Existing trong Settings để re-run pipeline layout lên mọi artboard có sẵn trong document. Hữu ích khi đã chỉnh JSON và muốn update mà không clone lại. Chỉ artboard có size suffix nhận được (300x250 / v2-300x250 / F2-300x250) mới bị tác động.

3.11 Refresh Source

Click Refresh Source (info card tab Settings) để re-detect artboard hiện hành từ selection hiện tại. Dùng khi đổi selection trong Photoshop giữa session — kể cả khi Cmd/Ctrl-click nhiều artboard.

3.12 Panel Logs

Panel dưới ghi log mọi hành động kèm timestamp:

  • Lỗi highlight đỏ + flash header 3s để gây chú ý.
  • Dòng "Complete" / "created" highlight xanh.
  • Lỗi tự expand panel nếu đang collapse.
  • Nút Copy copy toàn bộ log ra clipboard để share.
  • Nút Clear reset về Ready.
  • Click title Logs để collapse/expand.
  • Dòng [PERF] hiện khi DEBUG_PERF bật — round-trip timing để tune.

4. Auto-detect Export-mode

Khi click Export Layer JSON, plugin phân loại document thành 1 trong 3 mode — gửi hint đúng vào banner-cloner-v1.mode. Detect tự động; có thể override qua Settings → Override auto-detection.

ModeDetect khiWeb-ui dùng
single Selection chỉ có 1 artboard. Làm base size cho smart-pin reflow sang mọi extra size.
multi-frame N artboard, tất cả cùng WxH. Frame token (vd F1/F2/F3 hoặc Step1/Step2) được tách từ đoạn alphabetic-prefix cuối tên artboard. framePrefix set khi mọi frame chung prefix. Mỗi frame được reflow độc lập → output = frame × extra-size.
layer-full N artboard khác size (đã có sẵn full bộ size). Đẩy thẳng — generator render nguyên, không reflow.

Kết quả detect hiện live ở Settings → Export mode ngay khi có artboard. Dropdown override cho phép pick mode tay nếu detect sai (hiếm).

5. Asset Export Modes (A / B / C / D)

Mỗi dòng asset trong tab Assets có toggle size mode. Cycle bằng click vào nút mode.

ModeTác dụngPhù hợp với
A — Layer bounds Export layer ở full layer bound. Canvas output = size của layer. Logo, icon, shape độc lập muốn giữ full extent.
B — Clip to artboard Chỉ export phần intersect (visible) giữa layer và artboard. Canvas output = vùng overlap. Background tràn artboard — chỉ cần phần thực sự thấy được. Bị bắt buộc khi Custom output path đang set (cấu trúc folder per-size giả định BG đã clip).
C — Trim transparent Như A nhưng trim viền trong suốt khỏi kết quả. Asset kiểu sprite mà padding chỉ là pixel rỗng.
D — Edit Contents Mở source content của Smart Object và export cái đó. Skip với SO vector (log "skipped: vector smart object"). Smart Object raster muốn lấy resolution embedded gốc, không phải on-canvas.

Scale cho từng asset: 1× / 2× / 3× (mặc định 2× ngoài Advanced, 1× trong Advanced).

Format: PNG (mặc định) hoặc JPG (dùng JPG quality từ Advanced; mặc định 75).

6. Các format JSON & Schema

6.1 Schema mới: banner-cloner-v1 (output)

Sinh bởi Export Layer JSON từ v1.2.0+. Self-describing — mode rõ ràng, framePrefix (khi áp dụng), và frame cho từng artboard. Generator web-ui dùng trực tiếp.

{
  "schema": "banner-cloner-v1",
  "mode": "multi-frame",
  "framePrefix": "F",
  "exportedAt": "2026-05-04T10:00:00.000Z",
  "artboards": [
    { "artboard": "campaign-1200x628-F1", "frame": "F1", "width": 1200, "height": 628, "layers": [ ... ] },
    { "artboard": "campaign-1200x628-F2", "frame": "F2", "width": 1200, "height": 628, "layers": [ ... ] }
  ]
}

6.2 Rules format (canonical, để import)

Viết tay hoặc sinh bởi tool sister. Shape:

  • moduleName — campaign / module label, hiện ở info card Settings.
  • sizes[] — list { name, width, height }. Drive size key dùng để lookup rule.
  • elements[] — entry per-layer với override per-size cho position, size, font size, color, scale, …

6.3 Layer-full format (PSD tree, để import)

Output của Export Layer JSON mode layer-full (hoặc tool sister). Auto-detect khi import qua isLayerFullFormat() và convert sang rules format. Dùng nội bộ để:

  • Round-trip design qua tool ngoài.
  • Reuse full layer tree của 1 master làm spec cho mọi size.
  • Bind src của rule sang tên file PNG export thật (sau khi chạy Export Assets).

6.4 Quy ước tên file / artboard

  • Size thuần — 300x250: 1 layout / dim.
  • Variant — v1-300x600, v2-300x600: nhiều layout thay thế / dim.
  • Frame — F1-300x600, F2-300x600 (hoặc Step1-…): frame step-animation / dim.
  • Compound — campaign-300x600-F2: prefix + dim + frame token. Plugin parse được mọi dạng này qua parseFrameToken() + regex variant.

8. Tips & Conventions

  • Đặt tên group BG master là GG-background để tự cover-scale, không cần config.
  • Prefix GG- cho layer muốn rule quản (vd GG-headline, GG-cta). Kết hợp Require GG- prefix được convention opt-in sạch sẽ.
  • Sizes lưu localStorage, input field tự điền lại lần launch sau. Trạng thái toggle (Uniform / Smart / GG-prefix / Frame-match) cũng lưu.
  • Dùng Import JSON để áp template rule cho cả campaign 1 lần. Auto-fill cũng update Target Sizes input.
  • Cần 2 layout variant cùng dim (vd 300x600 portrait + landscape), dùng v1-300x600 và v2-300x600. Dim single-variant tự collapse về 300x600 lúc import.
  • Banner step-animation: đặt tên frame nguồn ...-F1, ...-F2, ...-F3. Cmd/Ctrl-click cả 3 làm nguồn, target prefix F1- / F2- / F3-, để Match source frame token route mỗi frame về target đúng.
  • Refresh Source nếu đổi selection giữa session — re-detect artboard hiện hành.
  • Asset export với Custom output path, chạy Export Assets trước Export Layer JSON để field src trong JSON trỏ đến PNG/JPG thật, không phải raw .ai/.psd.
  • Log panel auto-scroll; dùng Copy trên cùng để grab toàn bộ log share trong ticket.
  • Artboard clone lệch vị trí → click Refresh Source rồi clone lại — plugin re-anchor từ cạnh phải ngoài cùng.

9. Hạn chế hiện tại

  • Auto-layout smart-match chỉ best-effort; design phức tạp vẫn cần cleanup tay.
  • Asset export Mode D (Edit Contents) chỉ work với Smart Object raster — vector SO bị skip (kèm log).
  • Custom output path yêu cầu folder root tồn tại sẵn — không auto-create. Validate flash đỏ field nếu sai.
  • JPG export cap width 3000px (scale xuống); PSD lưu full resolution.
  • Chỉ hỗ trợ Photoshop (UXP). Min host version: 23.0.0 (manifest v5, apiVersion 2).
  • Color descriptor của Photoshop lưu green channel thành grain trong vài context — reader phải check cả 2 field để tránh artifact magenta khi G=0 (hàm readRGB của plugin xử lý sẵn).
  • Frame-token match yêu cầu tên nguồn chứa đúng -F1, -F2, … — không phân biệt hoa thường nhưng prefix alphabetic phải nhất quán giữa các frame.
  • Multi-source clone chỉ trong 1 document; clone ngang giữa nhiều file PSD chưa hỗ trợ.

10. Cài đặt

  1. Cài Adobe UXP Developer Tool (download free từ Adobe).
  2. Trong UXP DT, click Add Plugin và chọn file manifest.json trong folder này.
  3. Click Load. Panel xuất hiện trong Plugins ▸ Banner Cloner ở Photoshop.
  4. Panel dock bên phải; min size 320×520, preferred 360×760 (docked) / 420×820 (floating). Resize được tới 1200×2000.
  5. Plugin id: com.oai.bannercloner.v2. Quyền yêu cầu: full filesystem, code generation from strings, clipboard read/write.
