<color=#hex>…</color> Change text color. 3- or 6-digit hex, optional #.

<font="Style">…</font> Switch style within the current family. Use the style name from Photoshop's Character panel.
<font="Bold">Pioneer</font>
<font="Medium">subtitle</font>
<font="Light">thin</font>
<font="Black">HEAVY</font>
<font="Bold Italic">mixed</font>
<font="Condensed Medium">x</font>
<font=PSName>…</font> Switch to a completely different face by PostScript name (must be installed on this machine).
<font=Roboto-Bold>x</font>
<font="ArialMT">x</font>
<font=Helvetica-Oblique>x</font>
<font="TimesNewRomanPS-BoldMT">x</font>
Nesting: tags can be combined. <b><color=#f00>BOLD RED</color></b> → bold + red at the same time.
Case-insensitive: <B>, <Color=#FFF>, <FONT="bold"> all work the same.
Quoting: any attribute value with spaces must be quoted — <font="Bold Italic">, not <font=Bold Italic>.
Font tag auto-detect: values containing - or ending in MT/PS are treated as PostScript names (full face switch); plain words (Bold, Light, etc.) keep the current family and just change the style.
Bold/italic fallback: if a style face is not installed (e.g. <font="Italic"> on a family without an Italic face), Photoshop falls back to Regular and faux bold/italic is applied so the look is preserved.
Validation: bad syntax is highlighted under the input and Apply stays disabled until you fix it. Errors caught: unknown tags, unclosed/unmatched tags, nested duplicates, bad hex, missing attributes.
Full example:
SAVE <b><color=#ff0000>$1,500</color></b> on the all-new <font="Bold">Pioneer 1000</font><sup>®</sup>. <i>Limited time</i> — APR from <b>1.9%</b> for 72 months<sup>*</sup>
