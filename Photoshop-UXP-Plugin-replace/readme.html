Content Replacer

Photoshop UXP Plugin v0.2.33 by Thien Ho · Technical Solution

Tổng quan

Content Replacer là plugin Photoshop (UXP) giúp các bạn Designer / Studio thay nội dung hàng loạt trên file PSD nhiều artboards (hoặc nhiều file PSD mở cùng lúc). Một lần khai báo — plugin tự tìm tất cả layer trùng tên ở mọi artboard và thay đồng loạt: sửa text (kèm style tag in đậm / nghiêng / màu / superscript / đổi font ngay trong nội dung), đổi ảnh trong Smart Object, đổi tên layer, đổi tên artboard (template {WxH} hoặc Find & Replace), thêm text layer mới, gộp Smart Object trùng ảnh thành bản dùng chung để giảm dung lượng, hoặc chạy Photoshop Action lên các layer đã chọn.

Phù hợp với ai?
Workflow banner / KV nhiều size — ví dụ 1 PSD có 20 artboards (300x250, 728x90, 970x250…), hoặc 20 file PSD riêng cho từng size. Thay vì sửa từng artboard / từng file, plugin xử lý 1 lần cho tất cả.

Cài đặt

  1. Mở Adobe UXP Developer Tool (nếu chưa có, tải tại Creative Cloud Desktop).
  2. Add Plugin → Add Existing Plugin, chọn file manifest.json trong thư mục plugin này.
  3. Load plugin. Trong Photoshop: Plugins → Content Replacer để mở panel.
  4. Yêu cầu: Photoshop 23.0 trở lên.

Quy trình sử dụng cơ bản

  1. Mở file PSD trong Photoshop. Nếu mỗi size là một file PSD riêng → mở tất cả.
  2. Chọn Scan mode:
    • Current document — file đang active (PSD nhiều artboards).
    • All open documents — quét tất cả file PSD đang mở.
    Tuỳ chọn Match by layer name only: gộp các layer cùng tên kể cả khi nằm khác đường dẫn (group).
  3. Nhấn Scan document. Plugin liệt kê toàn bộ layer (text / image / group / other), kèm số occurrences — ví dụ 10/12 nghĩa là layer xuất hiện ở 10 trên 12 artboards đang bật.
  4. Trong mục Artboards, bỏ chọn artboard nào không muốn áp dụng. Plugin chỉ tác động lên các artboard đang được tick.
  5. Điền nội dung mới cho từng layer (xem các chức năng phía dưới), rồi nhấn Apply ở cuối panel. Sau đó nhấn Save để lưu lại các file đã chỉnh.

Các chức năng chính

1. Thay nội dung text
Nhập text mới vào ô textarea của layer. Plugin giữ lại định dạng (font, size, màu, mixed style) ở mức tốt nhất có thể bằng thuật toán LCS map giữa text cũ và text mới.
2. Style tag trong text
Định dạng từng đoạn ngay trong nội dung bằng tag: <b>, <i>, <sup>, <sub>, <color=#hex>, <font="Bold">, và \n (soft return). Có sẵn Style tag cheatsheet + kiểm tra cú pháp; sai sẽ chặn Apply đến khi sửa.
3. Thay ảnh Smart Object
Với layer image (pixel / smartObject), nhấn Browse… chọn file mới (PNG, JPG, PSD, TIFF, AI, SVG, PDF…). Plugin replace contents và giữ transform của smart object.
4. Đổi tên layer hàng loạt
Điền New name cho một layer → plugin đổi tên layer đó ở mọi artboard cùng lúc. Có nút Update để rename ngay không cần Apply.
5. Đổi tên artboard
Hai chế độ: Template với placeholder size — {WxH}, {WxH:0.5} (÷2), {WxH:2} (×2) — ví dụ test1_{WxH}_OP1; hoặc Find & Replace chỉ đổi 1 chuỗi, giữ nguyên phần còn lại. Nút Preview xem trước trước khi áp dụng.
6. Append Text Layer
Tạo thêm 1 text layer giống nhau lên tất cả artboards đang bật. Cấu hình font, size, line-height, màu, box-width, align, anchor X/Y, offset. Sample from selection copy thuộc tính từ text layer đang chọn; Auto-sync with selection tự cập nhật theo layer bạn đang chọn trong Photoshop.
7. Gộp Smart Object trùng ảnh
Mục Duplicate images phát hiện các Smart Object dùng chung 1 file ảnh nhưng là instance độc lập (sửa 1 cái không cập nhật cái khác, và PSD phình to). Nhấn Convert để gộp thành shared clone: sửa 1 lần áp cho tất cả + giảm dung lượng. Phân loại theo mức an toàn safe / warn / skip.
8. Run Photoshop Action
Tab Run Photoshop Action: chọn 1 hoặc nhiều layer, chọn Action Set + Action từ palette Actions của Photoshop, plugin chạy action lên từng layer đã tick.
9. Show / Locate layer
Nút Show ở mỗi dòng nhảy đến đúng layer trong Photoshop và highlight nó — tiện để kiểm tra trước khi sửa.
10. Lọc & tìm kiếm
Bộ lọc theo loại (Text / Image / Group / Other), tìm kiếm theo tên layer, tìm artboard theo tên. Hỗ trợ Select All / Deselect All theo filter hiện tại.

Lồng tag & kiểm tra cú pháp
Tag có thể lồng nhau: <b><color=#f00>BOLD RED</color></b>. Không phân biệt hoa thường. Giá trị có dấu cách phải đặt trong ngoặc kép (<font="Bold Italic">). Cú pháp sai (tag lạ, chưa đóng, hex sai, thiếu attribute…) sẽ hiện cảnh báo dưới ô nhập và chặn Apply đến khi sửa xong.

Mẹo thực chiến

Link ID — đồng bộ nhiều layer
Mỗi dòng có ô Link ID. Nếu hai layer có cùng Link ID, khi bạn sửa text ở dòng A, dòng B sẽ tự apply cùng nội dung. Hữu ích khi cùng 1 thông điệp xuất hiện ở nhiều layer khác tên.
Lưu ý về định dạng text
Plugin cố gắng giữ mixed style (chữ in hoa, màu khác nhau, font khác nhau trong cùng 1 layer). Tuy nhiên với text quá phức tạp, hãy kiểm tra lại sau Apply. Trống ô textarea = bỏ qua layer đó.
Save một lần cho tất cả
Sau Apply, nút Save sẽ lưu tất cả document đã bị chỉnh sửa. Không cần chuyển từng tab Photoshop để Ctrl+S.

Overview

Content Replacer is a Photoshop UXP plugin built for designers and studio teams who need to batch-edit content across multi-artboard PSDs (or many PSDs at once). Declare your changes in one panel — the plugin matches layers by name across all artboards and applies edits in bulk: replace text (with inline style tags for bold / italic / color / superscript / font switching), swap smart-object images, rename layers, rename artboards (template {WxH} or Find & Replace), append a new text layer, merge duplicate smart objects into shared clones to shrink file size, or run a Photoshop Action against selected layers.

Who is it for?
Banner / key-visual workflows with many sizes — e.g. one PSD with 20 artboards (300x250, 728x90, 970x250…), or 20 separate PSDs. Instead of editing each artboard or file by hand, do it once for everything.

Installation

  1. Open Adobe UXP Developer Tool (install via Creative Cloud Desktop if missing).
  2. Add Plugin → Add Existing Plugin and pick the manifest.json in this plugin folder.
  3. Load the plugin. In Photoshop, open Plugins → Content Replacer.
  4. Requires Photoshop 23.0 or newer.

Basic workflow

  1. Open the PSD(s) in Photoshop. If each size is a separate PSD, open them all.
  2. Pick a Scan mode:
    • Current document — the active file (a multi-artboard PSD).
    • All open documents — every PSD currently open.
    Optional Match by layer name only: groups layers that share a name even if their group paths differ.
  3. Click Scan document. The panel lists every layer (text / image / group / other) with an occurrences count — e.g. 10/12 means the layer exists in 10 of the 12 enabled artboards.
  4. In the Artboards section, untick any artboard you want to skip. The plugin only touches enabled artboards.
  5. Fill in the new content for each layer (see features below), then click Apply. Click Save to write changes back to disk.

Core features

1. Text replacement
Type new text in the row's textarea. The plugin preserves formatting (font, size, color, mixed styling) as best as possible via an LCS-based mapping between old and new text.
2. Inline style tags
Format spans right inside the text with tags: <b>, <i>, <sup>, <sub>, <color=#hex>, <font="Bold">, plus \n (soft return). A built-in Style tag cheatsheet and live syntax validation (Apply stays disabled until errors are fixed).
3. Smart-object image swap
For image layers (pixel / smartObject), click Browse… and pick a new file (PNG, JPG, PSD, TIFF, AI, SVG, PDF…). The plugin replaces contents and keeps the smart object's transform.
4. Bulk layer rename
Type a New name for a layer — every matching layer across all artboards is renamed at once. Use the Update button for an instant rename without going through Apply.
5. Artboard rename
Two modes: Template with size placeholders — {WxH}, {WxH:0.5} (÷2), {WxH:2} (×2) — e.g. test1_{WxH}_OP1; or Find & Replace swapping one substring and keeping the rest. A Preview button shows the result before you commit.
6. Append Text Layer
Drop an identical new text layer onto every enabled artboard. Configure font, size, line-height, color, box width, alignment, X/Y anchor, and offset. Sample from selection copies properties from the selected text layer; Auto-sync with selection keeps the form in sync with whatever layer you select in Photoshop.
7. Merge duplicate images
The Duplicate images section finds smart objects that share the same source file but are independent instances (editing one doesn't update the others, and the PSD bloats). Hit Convert to merge them into shared clones: edit-once-applies-to-all + smaller files. Grouped by safe / warn / skip risk tiers.
8. Run Photoshop Action
Switch to the Run Photoshop Action tab, tick layers, pick an Action Set + Action from Photoshop's Actions palette, and run it on each ticked layer.
9. Show / locate layer
The Show button in each row jumps to the layer in Photoshop and highlights it — useful for sanity-checking before Apply.
10. Filter & search
Filter by kind (Text / Image / Group / Other), search by layer name, and search artboards by name. Select All / Deselect All respect the active filter.

Inline style tags

In any layer's text field you can wrap spans in tags to format parts of the copy — no need to split layers. Open the in-panel Style tag cheatsheet for the full reference with examples.

TagEffectExample

<i>…</i>Italic (faux if no face)<i>Terms apply</i>

Nesting & validation
Tags can be combined: <b><color=#f00>BOLD RED</color></b>. They're case-insensitive, and any value containing spaces must be quoted (<font="Bold Italic">). Bad syntax (unknown/unclosed tags, bad hex, missing attributes…) is flagged under the input and keeps Apply disabled until you fix it.

Power-user tips

Link ID — sync changes across rows
Each row has a Link ID. Two rows sharing the same Link ID stay in sync — change text in row A and row B applies the same content. Handy when the same copy lives on multiple differently-named layers.
Mixed text styling caveat
The plugin tries to preserve mixed styling (uppercase runs, varied colors/fonts inside a single layer). For very complex text, double-check the result after Apply. An empty textarea means "skip this layer".
One Save for everything
After Apply, the Save button writes every modified document at once — no need to tab through Photoshop and Ctrl+S each file.

Troubleshooting

The plugin doesn't show up in Photoshop Make sure UXP Developer Tool has Loaded the plugin. Restart Photoshop the first time you add it.
Scan says "No active document" Open a PSD in Photoshop first and ensure it's the active document, then Scan.
Text Apply produces missing fonts Make sure the original font is installed. The plugin reuses each layer's existing font; if it's missing, Photoshop falls back to a default font.
Image swap doesn't fit the frame Replace-contents preserves the smart object's transform. If the new image has a different aspect ratio, adjust the smart object manually after Apply.
Run Action can't find my action The action set must be loaded in Photoshop's Actions palette. Click ↻ to reload the list.
Apply is disabled even though I typed text Usually a style-tag syntax error. Check the red warning under the input (unclosed tag, bad hex, missing attribute…) and fix it — Apply re-enables once the syntax is valid.
Convert duplicate images skips some layers The plugin sorts candidates into safe / warn / skip tiers. Layers in the skip tier (e.g. complex smart filters or masks) need a manual check — only convert them when you're sure.
