1. Overview

SVG Inspector lets you upload an SVG file and check it against a brand color palette, inspect fonts, and highlight specific elements — all in the browser, no plugins or installs required.

Color Tab

Compare colors in your SVG against a predefined palette. See which colors match and which are off-palette.

Font Tab

List all fonts used in the SVG with details: family, weight, size, color. Detect missing fonts on your machine.

2. Getting Started

New here? Download example SVG to try out the tool.
  1. Upload a SVG file — Drag and drop onto the left panel, or click to browse.
  2. Preview — The SVG renders immediately in the left panel.
  3. Set up a palette — In the Color tab on the right, create a profile and enter your brand colors.
  4. Scan — Click Scan & Check Colors to analyze the file.
  5. Review results — Check the Color and Font tabs for detailed findings.

3. Color Check

Setting Up a Palette

  1. Click New to create a profile (name defaults to your file name).
  2. Enter colors in the textarea — one hex per line. See Palette Format below.
  3. Or click Import JSON to load from a JSON file.
  4. Or click Pick from file to auto-extract all unique colors from the uploaded SVG.
  5. Click Save to persist the profile (stored in browser localStorage).

Running a Check

  1. Adjust the Tolerance slider if needed:
    • 0 = exact hex match only
    • 15-30 = recommended for SVGs exported from Illustrator (CMYK to RGB conversion may shift colors slightly)
  2. Click Scan & Check Colors.

Reading Results

  • Color match — All colors in the file exist in your palette.
  • Color no match — Some colors are off-palette.
  • Off-palette items show the nearest palette color and the diff value (max channel difference, 0-255).
  • Matched section is collapsed by default — click to expand.
  • Click a hex code to copy it to clipboard.

4. Font Check

After scanning, the Font tab shows all text styles found in the SVG, grouped by unique combination of family + weight + size + color.

Each card shows:

  • Font family — cleaned from PostScript names (e.g. HelveticaNeueforTFS becomes Helvetica Neue for TFS)
  • Weight — numeric value with label (e.g. 400 (Regular), 700 (Bold))
  • Size, style, color, letter-spacing
  • PostScript name — the raw font name from the SVG
  • Sample text — first few characters using this style
  • MISSING — font is not installed on your machine

Click a card to expand full details. Click again to collapse.

5. Highlight & Select

Both Color and Font items have a select button ◎ that highlights corresponding elements in the SVG preview.

  • Click ◎ — highlights all elements using that color or font with a dashed pink outline.
  • Highlight stays visible until you click another select button or press Esc.
  • Click the same ◎ again to toggle off.
  • The preview auto-scrolls into view when highlighting.
This is useful for identifying which elements in a complex SVG use a particular off-palette color or an unexpected font.

6. Export Report

After scanning, click Export Report (.xls) to download an Excel file with two sheets:

  • Font Check — columns: #, Font Family, Weight, Style, Size, Color, Count, Sample
  • Color Check — columns: #, Status (MATCHED / OFF-PALETTE), Hex, Sources, Count, Nearest Palette, Diff

Off-palette rows are highlighted in red. The file opens in Excel, Numbers, or LibreOffice.

7. Palette Format

Textarea Input

Enter one color per line. All formats below are supported:

#E71316 // Red 032
#00677F // Teal
#F1B434
// This is a comment (skipped)
Black  #021C42

JSON Import

Click Import JSON to load a file with this structure:

{
  "name": "Brand Palette",
  "colors": [
    { "name": "Red 032", "hex": "#E71316" },
    { "name": "Teal",    "hex": "#00677F" },
    { "hex": "#9BD3DD" }
  ]
}

Also supports a flat array format:

[
  { "name": "Red 032", "hex": "#E71316" },
  "#00677F"
]
