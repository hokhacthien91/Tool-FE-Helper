Video Resize guide

One finished .aep at one size → an MP4 per size you type, plus a working .aep with a comp per size.

Start1 Intake2 Roles3 Review4 Render AutoFilesLimits

Middlesex 10s-LAND 1920x1080 → 1080x1920. Waits sped up; the real run takes about 4.5 min.

Start

  • Open After Effects, then double-click Start Video Resize (.command on Mac, .bat on Windows). First run installs Python, about 1 min.
  • Later: Quick Start. Keep the terminal window open; closing it stops the tool.
  • Mac blocks the file? Run bash app/run.sh in Terminal once. Asked to let Terminal control After Effects: OK.
  • While the yellow bar shows, don't touch After Effects.

1Intake

  • Paste the .aep path → Read file. The original is never written; the tool works on a copy.
  • Pick the master comp (suggested = the tool's guess) and the sizes (even numbers only).
  • ❌ missing font → install it, or tick continue anyway.

2Layer roles 👤 You check

BACKGROUNDFill: covers the frame, sides cropped
CONTENTFit: text and logos stay inside, get smaller
SUBJECTBetween the two: person or product, keeps its edge
FOLLOWS PARENT / IGNORENot touched

Check the yellow ⚠ rows, fix any wrong role → Confirm roles → Build.

3Review sizes 👤 You check

FAILEdge uncovered or layer stretched. Must fix.
WARNText out of frame, text inside a background, scene cropped, expression. Look closely.
PASSNothing found at the sample times.

Each message ends with Fix:. Click a frame to compare it with the master; tick Safe area (yellow = keep text inside).

  1. Change a value (Content X/Y, Text/logo ×, Background ×…) → Apply rebuilds.
  2. Good → choose ✅ OK → Apply. Only OK sizes render.
  3. Can't fix with values → ✋ Edit by hand in AE, save in AE, Re-read from AE.

4Render & deliver 👤 You check

  • Watch every MP4: the checks only saw the sample times.
  • Export report.html to share. Copy deliverables → MP4s, .aep, report into <folder>/<master>_resize/.

Auto

Tick Auto in step 1: guessed roles, every size without FAIL rendered, report built. Stops on visible missing footage or a FAIL. Best for simple, familiar files.

Files

Video Resize/jobs/<job>/: working .aep, mp4/, report/. Removed jobs go to jobs/_trash/.

Limits

  • Text inside per-scene precomps is not re-laid out (Showa, MTM).
  • No brand-guideline checks, no PSD layouts yet.
  • Very tall/wide sizes, 3D cameras, rotated layers: edit by hand.
