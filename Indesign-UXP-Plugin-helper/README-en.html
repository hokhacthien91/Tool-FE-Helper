1. Install & Open

  1. Open Adobe UXP Developer Tool.
  2. Add Plugin → select the Indesign-UXP-Plugin-helper folder (the one with manifest.json).
  3. In InDesign: Window → Extensions → Banner Helper.
Quick reload while developing: in the UXP Developer Tool, click Reload on the plugin row.

2. Quick Start — 30-second tour

  1. Open the InDesign document you want to check.
  2. Calculator: select a logo frame on the canvas → click + Add selection as logo → see the area calculated using the client ratio.
  3. Scale Check: auto-scans on open. A red badge on the tab shows the issue count. Click the tab to see a list of broken-ratio graphics with a Select button to jump to each frame.
  4. Relink: when links go missing or paths change, scan + pick a new folder → relink in bulk.

3. Calculator Tab — Logos

Calculates each logo's area using the client ratio, plus the document total. Useful for quoting and brand-coverage percentage reports.

3.1 Add a logo

  1. Select a frame in InDesign.
  2. Click + Add selection as logo.
  3. A dialog prompts for a name + client → OK.

Each row shows: name, client, dimensions (W × H), area (W × H × ratio). Click the name to edit; click the empty row area to select that frame in InDesign.

3.2 Page filter & Compact view

Multi-page document → page filter bar at the top. Click a page to filter logos to it. The currently active page is highlighted in green.

The ≡ icon toggles compact view (denser rows, less meta).

3.3 Totals + Copy CSV

Footer shows total logo count + total area. Copy CSV copies the full list to the clipboard for pasting into Excel/Sheets.

3.4 Report frame (auto-updating)

Purpose: render a summary table inside the InDesign doc that auto-updates as you add/edit/remove logos.

  1. Create an empty text frame in the doc, wherever you want the report.
  2. Select it → in the plugin, click Link selected frame.
  3. Enter a Title (e.g. "QSR Percentages").

Output in the frame: Title All = ... + a 4-column table (Label | Square | = | Pct%). Text styling is preserved — the plugin only replaces content.

Unlink to stop auto-updates.

3.5 Document name (stamp filename)

Select a text frame → click Link & insert → the plugin writes the doc's filename (without .indd) into that frame. It updates automatically if the file is renamed.

3.6 Share — Export / Import

Export: saves logos + clients + settings to a .json file. Good for backups or moving a setup between machines.

Import:

  • Client name conflict → prompts Override / Rename / Skip.
  • Logo list → fully replaced (asks for confirmation if you already have data).
  • Title + unit → overwritten if present in the file.

4. Calculator — Settings

4.1 Display unit

Display unit: Auto (follows the doc's ruler) or fixed: px / mm / cm / in. All math runs in points internally — only the display changes.

4.2 Clients

Every logo is tied to a client. A client has a name + ratio (multiplier applied to the raw area when billing).

Defaults:

ClientRatio
Pilot0.587
Flying0.556
Generic1.0

Use + Add client to add more. Click Save settings to persist (stored in localStorage, applies across every document).

5. Relink Tab

Bulk-fix missing/out-of-date links when switching machines, moving projects, or renaming folders.

5.1 Relink to Folder

  1. Scan missing — lists missing links. Scan all = lists everything with its status.
  2. + subfolders checkbox (default ON): walks into subfolders when relinking.
  3. Choose the relink action that fits your situation:
ButtonScopeWhen to use
Pick folder & relink missing Missing links only Everyday use — safe, leaves currently linked files untouched
Redirect all links to folder… All links (including currently linked) Moving the entire project to a new server or folder — replaces even working links
Note on "Redirect all links": this button redirects every link — including ones that are currently working — to the folder you pick (matched by filename). Use it when moving all assets to a new location.
The "All opened docs" checkbox affects both scanning and the relink actions (Pick folder & Path Find & Replace). Enabled = every open document is touched. Disabled = active doc only.

5.2 Path Find & Replace (regex)

When only the path prefix changed (e.g. different user folder), no need to repick files one by one.

Example: copying a project from a teammate's machine to your own.

Pattern: /Users/anh\.le/
Replace: /Users/thien.ho/

Scope:

  • Missing links only — rewrite only the missing ones.
  • All links — rewrite everything, even links that are currently OK (use with care).

The Recent dropdown remembers the last 5 pattern/replace pairs — click to reload.

Careful: escape the dots in regex (\.). A bad pattern can break paths — Cmd+Z in InDesign reverts it.

6. Scale Check Tab

Detects placed graphics whose horizontal and vertical scale don't match (designer dragged a corner without holding Shift → logo is distorted). Auto-scans on plugin open / doc switch / geometry change.

6.1 Reading the result

Summary bar at the top:

  • ✓ All N placed graphics are proportional — everything's fine.
  • ⚠ X of N placed graphics have broken ratio — issues found.

The red badge on the Scale Check tab shows the issue count — visible from every other tab, so you don't need to be on Scale Check to know there's a problem.

6.2 Result rows

Each row in the issues list shows:

  • Link filename (e.g. logo-white.png) + page tag (p.1, p.2…)
  • W xx.x% / H xx.x% — current horizontal/vertical scale. The smaller value is highlighted red.
  • Δ xx.x% — the delta. Red when > 5%, amber when ≤ 5%.
  • Select button — jumps to the page and selects that frame in InDesign.

6.3 Filters

  • Vector only — only check .ai / .eps / .pdf / .svg (typical logo formats). Default OFF = check every placed graphic.
  • Current spread — only check the active spread (faster on long documents).

6.4 Pass list (proportional graphics)

Below the issues list, a green toggle ▸ Show N proportional graphics reveals the list of graphics that are currently OK — including their scale values (e.g. W 100% H 100%) so you can verify the plugin scanned the right things.

6.5 How to fix a broken-ratio logo

  1. Click Select on the issue row → the plugin jumps to the frame.
  2. In InDesign, press either:
    • Cmd+Alt+Shift+C — Fill Frame Proportionally (frame size kept, image scales evenly, may crop).
    • Cmd+Alt+Shift+E — Fit Content Proportionally (image scales evenly, no crop, may leave whitespace).
  3. The plugin re-scans within 500 ms → the row disappears from the issues list, the badge count drops.
Detection rule: horizontalScale !== verticalScale (tolerance 0.001%). So a graphic scaled evenly at 98% / 98% still PASSES, but 98.5% / 100% is flagged.

7. Logs Panel (shared)

Bottom of the plugin, shared by all three tabs. Click the header to expand/collapse.

  • Copy — copies all log output to the clipboard.
  • Clear — clears the log.

Useful when a relink or import fails — the log tells you which file and why.

8. FAQ / Tips

Which document does the plugin scan?

All tabs operate on the active document. Relink has an All opened docs option to scan/act on multiple documents at once.

Does data persist?

  • Logos — stored in the .indd doc label → travels with the file, shared with your team when you share it.
  • Settings (clients, unit, report title) — plugin localStorage → per machine.
  • UI state (page filter, compact view) — localStorage → per machine.

Does reloading the plugin lose data?

No. Logos are read from the doc label. Settings are read from localStorage. Reload only refreshes the UI.

Do I need to re-scan after switching documents?

No. The plugin polls every 500 ms and auto-detects doc switches → reloads data + re-renders.

Scale Check badge isn't updating?

  1. Make sure the correct doc is active (plugin scans the active doc only).
  2. Click the ⟳ Re-scan button inside the Scale Check tab to force.
  3. Deeply nested graphics inside groups are still scanned (we use doc.allGraphics).

Pick folder ran but nothing relinked?

  • Check the log — usually a filename mismatch (case sensitivity).
  • Turn on + subfolders if files are in a subdirectory.
  • If only the path prefix changed (same filenames) → use Path Find & Replace instead of Pick folder.

How do I ignore a logo I deliberately scaled non-proportionally?

Not supported in v1. Just skip that row in the list for now.
