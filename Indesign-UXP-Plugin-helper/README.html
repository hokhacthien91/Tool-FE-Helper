1. Cài đặt & mở plugin

  1. Mở Adobe UXP Developer Tool.
  2. Add Plugin → chọn folder Indesign-UXP-Plugin-helper (có file manifest.json).
  3. Trong InDesign: Window → Extensions → Banner Helper.
Reload nhanh khi dev: vào UXP Developer Tool, nút Reload ở plugin row.

2. Quick Start — 30 giây làm quen

  1. Mở doc InDesign muốn kiểm tra.
  2. Calculator: chọn 1 frame logo trong canvas → bấm + Add selection as logo → thấy diện tích tính theo client ratio.
  3. Scale Check: plugin tự scan khi mở, badge đỏ trên tab báo số lỗi. Click vào tab → list logo bị sai tỉ lệ, nút Select để nhảy tới frame.
  4. Relink: file link bị thiếu / đường dẫn đổi → scan + chọn folder mới → relink hàng loạt.

3. Tab Calculator — Logos

Tính diện tích từng logo theo ratio của client, và tổng diện tích. Dùng cho báo giá / tính phần trăm brand coverage.

3.1 Add logo

  1. Chọn 1 frame trong InDesign.
  2. Bấm + Add selection as logo.
  3. Dialog hiện ra: đặt tên + chọn client → OK.

Mỗi logo hiển thị: tên, client, kích thước (W × H), diện tích (W × H × ratio). Click tên logo để edit, click vùng trống trên row để select frame đó trong InDesign.

3.2 Page filter & Compact view

Doc nhiều page → thanh filter trên cùng hiện số page. Click để lọc logo của page đó. Page đang active có border xanh.

Icon ≡ = toggle compact view (row gọn hơn, ẩn bớt meta).

3.3 Total + Copy CSV

Footer hiển thị tổng số logo + tổng diện tích. Copy CSV copy toàn bộ list vào clipboard để paste vào Excel / Sheet.

3.4 Report frame (auto-update)

Mục đích: in bảng tổng kết ngay trong InDesign doc, tự update mỗi khi add/edit/xóa logo.

  1. Tạo 1 text frame trống trong doc (vị trí muốn show bảng).
  2. Chọn frame → plugin → bấm Link selected frame.
  3. Nhập Title (vd: "QSR Percentages").

Output trong frame: Title All = ... + bảng 4 cột (Label | Square | = | Pct%). Style text giữ nguyên, plugin chỉ thay nội dung.

Unlink để ngắt liên kết khi không muốn tự update nữa.

3.5 Document name (stamp tên file)

Chọn 1 text frame → bấm Link & insert → plugin ghi tên file (bỏ .indd) vào frame đó. Mỗi lần đổi tên doc, frame tự update.

3.6 Share — Export / Import

Export: lưu toàn bộ logos + clients + settings ra .json. Dùng để backup hoặc share setup sang máy khác.

Import:

  • Client trùng tên → prompt Override / Rename / Skip.
  • Logo list → replace hoàn toàn (có confirm nếu đang có data).
  • Title + unit → overwrite nếu file có.

4. Tab Calculator — Settings

4.1 Display unit

Chọn đơn vị hiển thị: Auto (theo ruler của doc), hoặc fix: px / mm / cm / in. Tất cả tính toán nội bộ vẫn chạy bằng points — chỉ display đổi.

4.2 Clients

Mỗi logo gắn với 1 client. Client có name + ratio (hệ số nhân lên diện tích thực khi tính giá).

Default:

ClientRatio
Pilot0.587
Flying0.556
Generic1.0

+ Add client để thêm. Bấm Save settings để lưu (settings persist qua localStorage, áp dụng cho mọi doc).

5. Tab Relink

Fix link bị missing / out-of-date hàng loạt khi đổi máy, đổi đường dẫn, hoặc copy project sang folder khác.

5.1 Relink to Folder

  1. Scan missing — list các link bị missing. Scan all = list tất cả kèm status.
  2. Checkbox + subfolders (default ON): tìm sâu vào subfolder khi relink.
  3. Chọn hành động relink phù hợp:
ButtonScopeKhi nào dùng
Pick folder & relink missing Chỉ link đang missing Sử dụng hàng ngày — an toàn, không đụng link đang OK
Redirect all links to folder… Tất cả link (kể cả link đang hoạt động) Chuyển toàn bộ project sang server/folder mới — thay thế luôn cả link đang OK
Lưu ý với "Redirect all links": button này sẽ redirect tất cả link — kể cả những link đang hoạt động bình thường — về folder bạn chọn (match theo tên file). Dùng khi chuyển toàn bộ asset sang location mới.
Checkbox "All opened docs" áp dụng cả scan lẫn thao tác relink (cả Pick folder & Path Find & Replace). Bật nó = tất cả doc đang mở đều bị ảnh hưởng. Tắt = chỉ active doc.

5.2 Path Find & Replace (regex)

Khi chỉ phần đầu path đổi (vd: đổi user folder), không cần pick file lại từng cái.

Ví dụ: copy project từ máy đồng nghiệp sang máy mình.

Pattern: /Users/anh\.le/
Replace: /Users/thien.ho/

Scope:

  • Missing links only — chỉ rewrite link đang missing.
  • All links — rewrite tất cả, kể cả link đang OK (cẩn thận).

Dropdown Recent nhớ 5 cặp pattern/replace gần nhất — click để load lại.

Lưu ý: regex phải escape dấu chấm (\.). Chạy sai có thể làm link sai path — Undo (Cmd+Z) trong InDesign revert được.

6. Tab Scale Check

Phát hiện placed graphic bị scale không đều 2 chiều (designer kéo corner không giữ Shift → logo méo). Tự scan khi mở plugin / switch doc / khi có thay đổi.

6.1 Cách đọc kết quả

Summary bar (trên cùng):

  • ✓ All N placed graphics are proportional — toàn bộ OK.
  • ⚠ X of N placed graphics have broken ratio — có lỗi.

Badge đỏ trên tab Scale Check hiện số lỗi — thấy từ mọi tab khác, không cần phải ở trong tab Scale Check mới biết.

6.2 Row kết quả

Mỗi dòng trong list lỗi:

  • Tên file link (vd: logo-white.png) + tag page (p.1, p.2…)
  • W xx.x% / H xx.x% — scale ngang/dọc hiện tại. Giá trị nhỏ hơn được highlight đỏ.
  • Δ xx.x% — delta (chênh lệch). Đỏ khi > 5%, vàng khi ≤ 5%.
  • Nút Select — nhảy tới page + chọn frame đó ngay trong InDesign.

6.3 Filter

  • Vector only — chỉ check .ai / .eps / .pdf / .svg (thường là logo). Default OFF = check tất cả placed graphics.
  • Current spread — chỉ check spread đang active (nhanh khi doc dài).

6.4 Pass list (proportional graphics)

Dưới list lỗi có toggle xanh ▸ Show N proportional graphics. Click để xem danh sách các graphics đang OK — kèm scale values (vd W 100% H 100%) để verify plugin đã quét đúng.

6.5 Cách fix logo bị lỗi

  1. Click Select trên row lỗi → plugin nhảy tới frame.
  2. Trong InDesign bấm phím tắt:
    • Cmd+Alt+Shift+C — Fill Frame Proportionally (frame giữ size, image scale đều, có thể bị crop).
    • Cmd+Alt+Shift+E — Fit Content Proportionally (image scale đều, không crop, có thể để khoảng trống).
  3. Plugin tự re-scan sau 500ms → row biến mất khỏi list lỗi, badge giảm.
Tiêu chí detect: horizontalScale !== verticalScale (tolerance 0.001%). Nghĩa là scale đều 98% / 98% vẫn PASS, nhưng 98.5% / 100% thì FAIL.

7. Panel Logs (shared)

Dưới cùng plugin, dùng chung cho cả 3 tab. Click header để expand/collapse.

  • Copy — copy toàn bộ log vào clipboard.
  • Clear — xóa log.

Log hữu ích khi relink fail hoặc import bị lỗi — đọc để biết file nào, lý do gì.

8. FAQ / Tips

Plugin scan doc nào?

Tất cả tab đều làm việc trên active document. Riêng Relink có option All opened docs để scan nhiều doc cùng lúc.

Data có persist không?

  • Logos — lưu trong label của doc .indd → theo doc, share với team khi share file.
  • Settings (clients, unit, report title) — localStorage của plugin → theo máy.
  • UI state (page filter, compact view) — localStorage → theo máy.

Plugin reload mất data?

Không. Logos đọc từ doc label. Settings đọc từ localStorage. Reload chỉ refresh UI.

Switch doc có phải re-scan không?

Không. Plugin polling mỗi 500ms, tự detect doc switch → load lại data + render list.

Badge Scale Check không update?

  1. Check xem đã mở đúng doc chưa (plugin chỉ scan active doc).
  2. Bấm nút ⟳ Re-scan trong tab Scale Check để force.
  3. Nếu graphic nested sâu trong group → plugin vẫn quét (dùng doc.allGraphics).

Relink pick folder nhưng không relink được?

  • Check log — thường là tên file mismatch (viết hoa/thường).
  • Bật + subfolders nếu file nằm trong subfolder.
  • Nếu chỉ path đổi (không đổi tên file) → dùng Path Find & Replace thay vì Pick folder.

Muốn ignore 1 logo cố ý bị non-proportional?

Chưa hỗ trợ trong v1. Tạm thời bỏ qua row đó trong list.
