Image assets folder for DOCUMENTATION screenshots.

Place PNG/JPEG/SVG screenshots here using the recommended filenames:
- colors.png
- typography.png
- spacing.png
- duplicates_dialog.png
- import_flow.png
- settings_panel.png

Recommended size: 1200x700 (or width 1200) — export at PNG, optimize for web (<500KB).

How to capture:
1. Open Figma file and run plugin to generate the `Global Style` frame.
2. Fit the frame on screen, use your OS screenshot tool (macOS: Cmd+Shift+4 then Space to capture window) or Figma Export.
3. Save file with the exact filename listed above and drop into this folder.

After adding images, update `DOCUMENTATION/FEATURES.md` to reference them.
