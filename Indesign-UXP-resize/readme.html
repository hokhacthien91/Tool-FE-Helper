Page Guides Inspector

UXP Plugin · v1.1.0

InDesign UXP panel cho phép kiểm tra & áp dụng Page setup (Trim / Bleed / Margin / Columns) và tự động bố trí 6 brand component theo Airbus spacing dùng letter-A làm đơn vị đo.

Features

Page setup

Đọc / chỉnh Trim, Bleed, Margin, Columns cho document hoặc active page. Hỗ trợ unit selector riêng (in / mm / cm / pt).

Airbus spacing

Tự động resize & position 6 component: Logo, URL block, QR, Main-headline, Campaign-line, Sub-headline.

A-guide cloning (per-page)

Sinh A guide clones 50% opacity quanh mỗi component, gom vào một group "Guide" riêng trên từng page. A luôn full-size (đúng tỷ lệ); số lượng = ceil(count), shift vào trong để A ngoài cùng chạm đúng padding boundary.

Reference-based positioning

Component có thể anchor theo Trim / Margin / hoặc component khác (Logo, URL, QR…). Hệ 2-pass tự resolve dependency.

Per-document persistence

Mọi setting (names, anchors, A counts, refs, unit, collapse state) lưu vào document label — giữ giữa các session.

Undo as single step

Apply layout wrap trong UndoModes.ENTIRE_SCRIPT — Cmd+Z hoàn tác cả lượt apply trong 1 step.

Decimal A count + validation

A count nhập tự do số thập phân (vd 1.5, 2.5), range 0–5, 1 chữ số thập phân (auto làm tròn). Nhập sai → field viền đỏ + message inline.

Required-layer guard

Logo-airbus + letter-A bắt buộc tồn tại. Thiếu → input đỏ + nút Apply bị khoá. Component có layer tồn tại → checkbox tự tick.

Per-page targeting

Chọn page trong dropdown + nút Go để nhảy tới page đó. Apply chỉ sắp xếp object & guide của page đang chọn — mỗi page có bộ object trùng tên riêng, không kéo qua page khác.

Install & Run

Setup steps

1

Mở UXP Developer Tools

Trong Adobe Creative Cloud → Apps → "UXP Developer Tool" (cài nếu chưa có).

2

Add plugin

UDT → Add Plugin → chọn manifest.json ở thư mục này.

3

Load & Debug

Mở InDesign (>= 19.0). Trong UDT row của plugin → bấm Load → panel "Page Guides" xuất hiện trong Window menu.

4

Reload sau khi sửa code

Sửa index.html / index.js / styles.css → UDT → Reload. Không cần build.

Cache issue? Nếu lỗi lạ sau reload, chạy: rm -rf ~/Library/Caches/Adobe/UXP/ rồi reload lại.

UI Overview

Document Info

Hiển thị tên document và unit selector. Đổi unit → tất cả input numeric tự convert (in / mm / cm / pt). InDesign ruler không bị động đến.

Scope Toggle

  • Active page — Margin / Columns đọc-ghi theo trang đang chọn.
  • All pages — chế độ xem read-only, list page size + margin của tất cả pages.

Page Setup (collapsible)

4 card: Trim, Bleed, Margin, Columns. Trim & Bleed áp dụng cho cả document. Margin & Columns áp dụng cho active page.

Nút Apply page setup ghi tất cả values vào doc. Revert khôi phục snapshot trước khi sửa.

Airbus Spacing (collapsible)

7 input name + nút Set: gán tên cho object đang select trong InDesign. Tên không tồn tại → input vàng + component group disabled, badge "name not found".

Required layers: Logo-airbus và letter-A bắt buộc. Nếu thiếu, input của chúng viền đỏ + message "not found — required", và nút Apply spacing bị khoá cho tới khi cả hai tồn tại.

6 component groups: Logo / URL / QR / Main-headline / Campaign-line / Sub-headline. Mỗi group:

  • Checkbox — bật / tắt cho component đó. Khi layer chuyển từ thiếu → có (kể cả lần đầu), checkbox tự tick; nếu user chủ động bỏ tick (layer vẫn có) thì giữ nguyên lựa chọn.
  • Anchor H / V — Left / Right, Top / Bottom.
  • A count H / V — input số thập phân, range 0–5, tối đa 1 chữ số thập phân (auto làm tròn). Nhập rỗng / sai số / ngoài range → viền đỏ + message inline; có field lỗi thì chặn Apply.
  • Ref H / V — anchor theo Trim, Margin, hoặc component khác.

Workflow

Typical apply session

  1. Mở InDesign document có chứa các object cần layout.
  2. Select 1 object → nhập tên trong field tương ứng → bấm Set. Lặp lại cho từng component.
  3. (Optional) chỉnh page setup → Apply page setup.
  4. Tinh chỉnh anchor / A count / ref cho từng component nếu cần.
  5. Bấm Apply spacing. Plugin resize + position + tạo A clones trong layer "Guide" (auto-create nếu chưa có).
  6. Cmd+Z hoặc Undo spacing để hoàn tác.

Key Concepts

Letter-A là đơn vị đo

Plugin tìm object tên letter-A bên trong group Logo. Chiều rộng & cao của A trở thành unit để:

  • Tính padding của component so với reference (mỗi count = 1 A).
  • Clone A guide xung quanh component.

2-pass apply

Component reference Trim / Margin được resolve trước (pass 1). Component reference component khác (vd Camp ref Main, Sub ref QR) resolve sau khi component target đã đặt vị trí xong (pass 2).

A guide zones

  • Logo / URL / Main dùng zone builder thường — A xếp theo grid H × V.
  • QR / Camp / Sub dùng "Fixed 2A column": H side = cntH cột, mỗi cột = 2 A xếp dọc. V side = cntV A xếp dọc.
  • Camp & Sub luôn xếp H column từ mép dưới layer lên (force-bottom).
  • Số A vẽ = ceil(count), mỗi A full-size cách đều 1 bước (nối tiếp / lồng đỉnh, không méo). Count lẻ (vd 2.5) → stack shift vào trong ceil(count) − count đơn vị: A ngoài cùng chạm đúng padding boundary (trim), phần lẻ đè lên phía component.
  • Vị trí component vẫn dùng giá trị count chính xác (vd 2.5A) — chỉ guide mới làm tròn số lượng A.

UXP Constraints

Đọc trước khi sửa code! UXP runtime có những khác biệt quan trọng so với browser thông thường.
ConstraintWorkaround
require() top-level failGọi require("indesign") trong function body.
window.confirm / alert không hoạt độngBuild inline UI bằng DOM.
inset: 0 không hoạt độngViết đầy đủ top/left/right/bottom + width/height.
Spectrum CSS vars không hoạt độngDùng hard-coded hex.
innerHTML trên button phá hit-testingDùng createElement + addEventListener.

InDesign API gotchas

  • geometricBounds = [y1, x1, y2, x2] — không phải [x1, y1, x2, y2].
  • Image frame type là "Rectangle" — không phải "Image".
  • recompose() phải chạy trước khi restore textFramePreferences.
  • Luôn check isValid trong try/catch — frame reference có thể bị stale.
  • Không dùng FRAME_TO_CONTENT để auto-fit text — sẽ thay đổi geometry & phá layout.

Persistence

Mọi setting đi vào doc label key pageGuides.fitTarget.v1 (JSON string). Load khi mở doc, save khi user thay đổi bất kỳ input.

Reset & Undo

Buttons

  • Apply spacing primary — resize + position 6 component, clone A guides.
  • Undo spacing — restore bounds từ snapshot, xóa A clones đã tạo, unhide A's gốc.
  • Reset options — reset 6 component groups (anchor / A count / ref) về default. Không động đến name inputs, page setup, hay checkboxes.
  • Apply page setup primary — ghi Trim / Bleed / Margin / Columns vào doc.
  • Revert page setup — restore snapshot lúc plugin vừa load.

Troubleshooting

Triệu chứngNguyên nhân & Fix
"Object is locked" khi Apply spacing Layer "Guide" đang lock. Mở Layers panel → unlock layer Guide.
Component group hiện "name not found" Tên input không match layer/object trong doc. Đổi tên hoặc bấm Set sau khi select object.
Nút Apply spacing bị mờ / không bấm được Thiếu layer bắt buộc. Đảm bảo cả Logo-airbus và letter-A tồn tại trong doc (input của chúng không viền đỏ).
A count viền đỏ, không Apply được Giá trị rỗng / không phải số / ngoài range 0–5. Sửa theo message inline dưới field.
A clones bị lệch khỏi component Letter-A reference không đúng tỷ lệ. Check object letter-A bên trong Logo group — đảm bảo đó là chữ A đúng kích thước.
Plugin lag treo sau khi bấm Apply Có thể do item.fit() chạy trên text frame. Save doc, đóng InDesign, mở lại.
Sửa code không có hiệu lực Quên reload trong UDT. Hoặc cache stale — clear cache ~/Library/Caches/Adobe/UXP/.
