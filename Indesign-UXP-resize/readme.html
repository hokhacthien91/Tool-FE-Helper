Replace Tool

InDesign UXP Plugin v1.0.0 by Thien Ho · Technical Solution

Tổng quan

Replace Tool là plugin Adobe InDesign (UXP) giúp Designer / Studio thay nội dung text và hình ảnh hàng loạt trực tiếp trong tài liệu InDesign, không cần mở từng frame một. Plugin quét toàn bộ document, liệt kê tất cả text frame và image frame, cho phép khai báo nội dung mới rồi apply một lần cho tất cả.

Phù hợp với ai?
Workflow editorial / packaging / banner InDesign nhiều trang — ví dụ 1 file INDD có 50 trang, mỗi trang có các khung text / hình cần cập nhật nội dung khách hàng mới. Thay vì click từng frame, plugin liệt kê tất cả và cho phép điền nội dung trong một panel duy nhất.

Cài đặt

  1. Mở Adobe UXP Developer Tool (nếu chưa có, tải tại Creative Cloud Desktop).
  2. Add Plugin → Add Existing Plugin, chọn file manifest.json trong thư mục plugin này.
  3. Load plugin. Trong InDesign: Plugins → Replace Tool để mở panel.
  4. Yêu cầu: InDesign 19.0 trở lên (InDesign 2024+). Sau khi chỉnh sửa file plugin, nhấn Reload trong UXP Developer Tool — không cần build.

Quy trình sử dụng cơ bản

  1. Mở file InDesign (.indd). Nếu cần xử lý nhiều file cùng lúc, mở tất cả trong InDesign.
  2. Chọn Scan Scope:
    • Current document — chỉ quét file đang active.
    • All open documents — quét tất cả file đang mở.
    Tùy chọn Include master pages: quét thêm các frame nằm trên master page (labeled Master: [tên]).
  3. Nhấn ⊕ Scan Frames. Plugin liệt kê toàn bộ text frame và image frame trên mọi trang, kể cả frame nằm trong group lồng nhau.
  4. Trong mục Pages, bỏ tick những trang không muốn xử lý. Dùng nút All / None để chọn hoặc bỏ chọn tất cả. Danh sách frame sẽ tự lọc theo trang đang được chọn.
  5. Điền nội dung mới cho từng frame cần thay đổi, rồi nhấn ✓ Apply N Changes ở cuối panel. InDesign tự track undo — có thể hoàn tác bằng Ctrl+Z bình thường.

Các chức năng chính

1. Thay nội dung text frame
Nhập text mới vào textarea của từng frame. Plugin giữ lại toàn bộ định dạng (font, size, màu, căn lề ngang + dọc, inset spacing) bằng cách replace text trong paragraph hiện có — không tạo paragraph mới. Nhấn Ctrl+Enter để apply ngay frame đó mà không cần nhấn nút Apply All.
2. Thay hình ảnh (image frame)
Với frame hình ảnh (Rectangle / Oval / Polygon có chứa ảnh), nhấn 📂 Choose Image… để chọn file mới (JPG, PNG, PSD, AI, PDF, TIFF). Plugin tự tính scale để giữ đúng chiều rộng frame gốc sau khi đặt ảnh mới vào.
3. Frame có inline icon / AI anchor
Text frame có chứa icon hoặc file AI nhúng inline (anchored objects) sẽ hiển thị placeholder {{IMG_1}}, {{IMG_2}}… Giữ nguyên các placeholder này khi nhập text mới — plugin sẽ thay text xung quanh mà không đụng vào anchored objects.
4. Đổi tên frame
Mỗi frame card có ô Rename frame…. Click vào tên frame ở tiêu đề để tự động điền tên hiện tại vào ô. Nhấn Enter hoặc nút Rename để đổi tên ngay — có undo trong InDesign.
5. Locate frame
Nút Locate ở mỗi dòng nhảy thẳng đến frame trong InDesign (tự switch document nếu cần) và select frame đó — tiện để kiểm tra trước khi sửa.
6. Lọc theo trang (Pages)
Sau khi scan, mục Pages liệt kê tất cả trang có frame, kèm số text / image frame trên từng trang. Bỏ tick trang nào để ẩn frame của trang đó khỏi danh sách và loại khỏi Apply All.
7. Tìm kiếm & lọc loại frame
Ô tìm kiếm lọc theo tên frame, tên trang, tên document, hoặc nội dung text. Phím tắt Ctrl+F / Cmd+F focus thẳng vào ô tìm kiếm; Escape để xóa và đóng. Tab lọc: All / Text / Image.
8. Apply All + Progress
Nút ✓ Apply N Changes ở cuối panel hiển thị đúng số frame đang có nội dung mới chờ apply. Trong khi apply, progress bar hiện trạng thái từng frame. Toàn bộ thao tác được wrap trong một Undo step duy nhất trong InDesign.

Mẹo thực chiến

Anchor placeholder — không xóa {{IMG_n}}
Nếu frame text có icon hoặc ảnh inline, plugin sẽ block replace nếu bạn xóa mất placeholder. Chỉ cần edit phần chữ xung quanh placeholder — ví dụ:

Gốc: Gọi ngay {{IMG_1}} 1800 1234
Mới: Liên hệ {{IMG_1}} 0909 888 777 ✓
Sai: Liên hệ 0909 888 777 ✗ (mất placeholder)
Không cần Save riêng
Khác với Photoshop, InDesign không cần explicit save sau apply. Mọi thay đổi đã được ghi vào undo history — lưu file bình thường bằng Ctrl+S hoặc File → Save khi hoàn tất.
Scan nhanh — filter chậm
Scan trong InDesign rất nhanh (dưới 1 giây với 200 trang). Không cần lo ngại scan toàn bộ document rồi dùng Pages filter để ẩn những trang không cần — nhanh hơn là scan có chọn lọc.
Frame nằm trong group
Plugin dùng allPageItems để quét đệ quy toàn bộ group lồng nhau ở mọi độ sâu. Không cần ungroup trước khi scan.

Overview

Replace Tool is an Adobe InDesign UXP plugin that lets designers and studio teams batch-replace text and image content across InDesign documents without opening each frame individually. Scan the document once, fill in new content for any frame, and apply everything in one click.

Who is it for?
Editorial, packaging, and banner workflows in InDesign with many pages — for example, a 50-page INDD where every page has text and image frames that need fresh client content. Instead of clicking through each frame, the plugin lists everything in a single panel.

Installation

  1. Open Adobe UXP Developer Tool (install via Creative Cloud Desktop if missing).
  2. Add Plugin → Add Existing Plugin and pick the manifest.json in this plugin folder.
  3. Load the plugin. In InDesign, open Plugins → Replace Tool.
  4. Requires InDesign 19.0 or newer (InDesign 2024+). After editing plugin files, click Reload in UXP Developer Tool — no build step needed.

Basic workflow

  1. Open your InDesign file(s). If processing multiple documents at once, open them all in InDesign.
  2. Choose a Scan Scope:
    • Current document — the active document only.
    • All open documents — every document currently open in InDesign.
    Optional Include master pages: also scans frames on master pages (labeled Master: [name]).
  3. Click ⊕ Scan Frames. The plugin lists every text frame and image frame on all pages, including frames nested inside groups at any depth.
  4. In the Pages section, uncheck any pages you want to skip. Use All / None to toggle all at once. The frame list filters automatically to show only enabled pages.
  5. Fill in new content for each frame you want to change, then click ✓ Apply N Changes in the sticky footer. InDesign tracks the full operation as a single undo step — press Ctrl+Z to revert.

Core features

1. Text frame replacement
Type new text in a frame's textarea. The plugin preserves all formatting (font, size, color, horizontal and vertical alignment, inset spacing) by replacing text within the existing paragraph rather than creating a new one. Press Ctrl+Enter to apply just that frame instantly.
2. Image frame replacement
For image frames (Rectangle / Oval / Polygon with a placed graphic), click 📂 Choose Image… to pick a new file (JPG, PNG, PSD, AI, PDF, TIFF). The plugin scales the new image to preserve the original frame's width.
3. Inline icon / AI anchor support
Text frames containing inline anchored objects (icons, AI files) show {{IMG_1}}, {{IMG_2}}… placeholders. Keep these in your new text — the plugin replaces only the text segments between anchors without touching the anchored objects.
4. Rename frame
Each frame card has a Rename frame… input. Click the frame name in the card header to pre-fill the current name. Press Enter or the Rename button to apply — fully undoable in InDesign.
5. Locate frame
The Locate button in each row jumps directly to the frame in InDesign (auto-switches the active document if needed) and selects it — useful for a visual check before editing.
6. Per-page filter (Pages)
After scanning, the Pages section lists every page that has frames, with a text/image count per page. Uncheck any page to hide its frames from the list and exclude them from Apply All.
7. Search & filter
The search box filters by frame name, page name, document name, or text content. Ctrl+F / Cmd+F focuses the search bar; Escape clears it. Filter tabs: All / Text / Image.
8. Apply All + Progress
The ✓ Apply N Changes button shows the exact count of frames with pending content. During apply, a progress bar tracks each frame. All changes are wrapped in a single InDesign undo step.

Power-user tips

Anchor placeholders — don't delete {{IMG_n}}
If a text frame has inline icons or images, the plugin blocks replacement if you remove a placeholder. Only edit the text around the placeholder — for example:

Original: Call now {{IMG_1}} 1800 1234
New: Contact {{IMG_1}} 0909 888 777 ✓
Wrong: Contact 0909 888 777 ✗ (placeholder deleted)
No separate Save step needed
Unlike Photoshop, InDesign does not require an explicit save after apply. All changes live in the undo history. Save the file normally with Ctrl+S or File → Save when done.
Scan fast, filter per page
Scanning InDesign is very fast (under 1 second for 200 pages). There is no penalty to scanning the full document — use the Pages filter to show only the pages you care about instead of running a selective scan.
Frames inside groups
The plugin uses InDesign's allPageItems to recursively collect frames from groups at any nesting depth. No need to ungroup before scanning.

Troubleshooting

The plugin doesn't show up in InDesign Make sure UXP Developer Tool has Loaded the plugin. After a reload, sometimes closing and reopening the panel in InDesign is needed. To clear stale cache: rm -rf ~/Library/Caches/Adobe/UXP/.
Scan says "No document is open" Open an InDesign file first and make sure it is the active document, then click Scan.
Text replacement causes overflow The new text is longer than the frame can hold. The plugin logs a warning: "⚠ Text overflows frame". Adjust the font size or frame height manually after apply.
Vertical alignment is lost after text replace The plugin saves and restores verticalJustification automatically. If it still shifts, undo with Ctrl+Z and re-scan — the frame reference may have gone stale if the document structure changed since the last scan.
Locate button says "Frame no longer exists" The frame was deleted or its document was closed after scanning. Click ⊕ Scan Frames to refresh the list.
Image replace says "place() returned empty" InDesign could not place the file — it may be corrupted, an unsupported format, or have special characters in the path. Try a different file or rename it to remove special characters.
Error when scanning All open documents One of the open documents may be locked or unsaved. Make sure every open document has been saved at least once before scanning in All mode.
